# Goal 4 - WCAG 2.1 AA Accessibility Audit (2026-11-18)

## Scope
Full pass on portal UI: color contrast, keyboard navigation, screen-reader labels.

## Method
- Static analysis of ui/app.css + index.html
- Computed relative luminance + contrast ratios for all fg/bg pairs
- Scanned HTML for ARIA attributes, landmarks, focus states
