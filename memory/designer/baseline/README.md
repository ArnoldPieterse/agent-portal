# UI Regression Screenshot Baseline (Goal #10)

## Purpose
Cycle-3 visual baseline for all portal panels. Future CSS/JS changes must pass
a visual diff (<5% pixel change) against these captures without explicit sign-off.

## Files
| File | Role |
|------|------|
| `capture_baseline.py` | Captures screenshots at 3 resolutions x 8 panels (24 total) |
| `visual_diff.py` | Compares current state vs baseline; exits 0/1 |
| `MANIFEST.json` | SHA256 + metadata for each captured panel (generated by capture) |
| `shots/` | PNG screenshots (one per panel x resolution) |

## How to Run (NON-SANDBOX seat with Chrome)
```bash
pip install playwright pillow
python -m playwright install chromium

# Capture baseline:
python memory/designer/baseline/capture_baseline.py --url http://127.0.0.1:8099

# Later, verify a change hasn't broken visuals:
python memory/designer/baseline/visual_diff.py --threshold 5
```

## Panel List
dashboard, fleet, goals, ops, memory-tree, uploads, chat, settings

## Resolutions
- 1920x1080 (fullhd)
- 1366x768 (laptop)
- 1024x768 (tablet-landscape)

## Acceptance Criteria
- >= 8 panel screenshots captured successfully
- MANIFEST.json committed with SHA256 hashes
- visual_diff.py exits 0 on baseline-vs-baseline (sanity check)
