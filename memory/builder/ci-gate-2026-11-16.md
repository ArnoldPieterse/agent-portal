## Behavior
- Exit 0 = all green (commit allowed)
- Exit 1 = at least one suite failed (commit blocked, failing suite named + stderr tail shown)
- `--json` flag for machine-readable output
- `--verbose` for per-suite progress
- 120s timeout per suite; crash/timeout treated as FAIL
