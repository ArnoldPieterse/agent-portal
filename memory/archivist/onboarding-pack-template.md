# Onboarding Pack Template
Generated by: `memory/archivist/onboarding_pack.py`
Usage: `python memory/archivist/onboarding_pack.py <agent_name>`

## Structure
Each generated pack contains these sections in order:

1. **Role** - one-line description from memory/INDEX.md lane line
2. **Read First** - ordered list of key files (max 5), always starts with memory/INDEX.md
3. **Common Pitfalls** - agent-specific (from ops/blockers) + universal rules (max 4)
4. **Current Cycle Context** - topic + status from TODO.md top section + fleet goal %
5. **Quick Start Protocol** - 5-step numbered onboarding sequence

## Constraints
- Pack must be <4KB (enforced by selftest)
- Must pass 5-question comprehension test (>80% score)
- Handles unknown agents gracefully (fallback role description, "create this" for missing INDEX)

## Data Sources
| Section | Source | Fallback |
|---------|--------|----------|
| Role | memory/INDEX.md lane line | "Agent X (description not found)" |
| Key Files | memory/<agent>/INDEX.md file refs | "memory/<agent>/INDEX.md (create this)" |
| Pitfalls | memory/ops/blockers.md + universal | Universal only |
| Cycle | TODO.md top ## section | "See TODO.md" |
| Fleet % | goal_ledger.json | "see /api/goals" |

## Self-Test
```
python memory/archivist/onboarding_pack.py --selftest
```
Verifies: pack size <4KB, comprehension 5/5 questions pass for 'archivist' agent.
