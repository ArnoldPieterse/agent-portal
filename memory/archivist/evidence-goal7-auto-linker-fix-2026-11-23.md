## What was broken
The idempotency check in auto_linker.py selftest was failing (10/11). Root cause: the block-removal loop used `if i > 0` guard which caused immediate break at i=0 (the marker line), so end_offset stayed 0 and nothing was stripped. Each re-run appended a new AUTO-LINKS block, producing 3 blocks after 3 runs.

## Fix applied
Replaced the broken line-by-line loop with a single regex:
```python
raw_content = re.sub(r'\n?<!-- AUTO-LINKS \(generated by auto_linker\.py\) -->\n(?:- related: .+\n)*', '', raw_content)
```
This correctly strips the entire block (marker + all related lines) in one pass. Also refactored to use the already-stripped content for the write step, eliminating a redundant re-read.
