# kg_integrity.py supersession target-key fix (2026-11-19)

Owner of affected goal: **Archivist** (cycle-5 goal #1, Knowledge Graph Integrity Report).
Contributor: Orchestrator (ops correctness pass, auto-loop contribution option d).

## Bug (confirmed on disk, not just claimed)
`memory/archivist/kg_integrity.py` read the supersession target as `s.get("to", "")`,
but the live data in `memory/archivist/knowledge_graph.json` stores it under key `target`.
- All 343 supersessions have shape `(from, marker, target)`.
- `dict supersessions with non-empty 'to'` = **0**; with non-empty `'target'` = **340**.

Consequence: every supersession target was silently dropped from node collection,
inbound-edge credit, cycle adjacency, and the dangling-reference check. Only the raw
count in `edge_count` (len(edges)+len(sups)) survived. The shipped report's
"Total nodes = 475" matches the buggy BEFORE value, confirming it was generated by
the broken key.

## Fix
Added `_is_node_ref()` + `_sup_target()` helpers; supersession target now read as
`s.get("target") or s.get("to")`, and only real file-path targets are treated as graph
nodes (311/343 supersession "targets" are prose like 'the'/'nothing'/'r24' captured by
the parser — those must not pollute the graph; edges already use real paths). Applied to
all 4 supersession loops (nodes, inbound, dangling, adjacency). Backup: original logic
diffed in this file's git history.

## Before/after (same live JSON, 582 edges + 343 supersessions)
| Metric | BEFORE (reads 'to') | AFTER (reads 'target') |
|--------|--------------------|-----------------------|
| Total nodes | 475 | **496** (+21) |
| Edge count | 925 | 925 |
| Orphan count | 150 | 150 (unchanged — 21 new nodes all have sup inbound) |
| Dangling refs | 0 | **25** (previously invisible) |
| Cycle count | 3 | 3 |

The fix recovers 21 real-path supersession target nodes and exposes 25 dangling
supersession references that the wrong key had hidden. Regenerated report:
`memory/archivist/kg-report-cycle5.md` (now 496 nodes).
