1. CI gate on every portal edit - `pre_commit_gate.py` runs ALL four suites (path-safety, prune-regression, truncation-detect, playbook tests) and blocks the commit if any fail. Verified by injecting a bug into agent_portal.py and watching the gate refuse with the exact failing case named.
2. Canary deploy pipeline - `canary_deploy.py` stages a portal change to Red first, runs the smoke suite there, promotes to Black/Pale only if green. Verified end-to-end: good change lands on Red -> passes -> propagates; bad change caught at Red, never reaches the others.
3. Wedge auto-recovery daemon - `wedge_watchdog.py`: >90s stall captures a forensic snapshot (process tree, open handles, last 50 log lines), graceful restart, event appended to memory/ops/wedge-events.jsonl. Verified by simulating a hang: recovery fires + event logged with zero human intervention.
4. Evolution fitness integration - test suites wired as the scoring function in evolution.py; failing variants graveyarded automatically. Verified by one cycle where a test-failing variant is removed and a passing variant advances to `living`.
5. API contract pinning - `api_contract_test.py` records response schema (status, required keys, value types) of every /api/* endpoint into JSON fixtures; fails on drift. Verified: 100% endpoint coverage; renaming a field shows as CONTRACT_BREAK with the exact path.

7. Executable test playbook - `playbook_to_tests.py` parses memory/portal/testing.md edge-case tables into runnable tests; the doc is the single source of truth, tests are derived. Verified by adding an edge-case row -> new test appears and passes.
8. Perf SLO tiles (SLO pipeline, Builder role) - GET /api/perf tracks p50/p95/p99 per endpoint over a rolling 60-min window; sparkline tiles in the Ops panel fed by Mechanic#4 baseline data. Verified: hammering /api/uploads 100x updates p95 in-browser within 30s, matching manual measurement.
9. Hot-patch with auto-rollback - `hotpatch.py` applies a single-hunk diff to agent_portal.py without restart, runs the smoke suite, auto-restores the original on failure (<=30s). Verified by applying a deliberately broken patch: rollback fires, original behavior restored, no process restart.
10. Agent capability health matrix - GET /api/agents/health probes all 8 agents (ping latency, tool availability, last-seen); live green/yellow/red matrix in the portal header. Verified: all 8 green <5s; a stopped agent shows yellow within 60s, red after 120s.
