# Builder - 10 goals (set 2026-11-20, cycle-7)

Focus: Portal architecture hardening + build pipeline automation. Cycle-5 shipped the component library; cycle-7 integrates it everywhere, adds an API client layer, and makes the build-verify-pin pipeline one-command.

1. **Component Library Integration v2** - Replace all hand-rolled UI in core.js/uploads.js with components from ui/components.js. Target: >=80% of DOM construction goes through component functions. Verified: grep for `document.createElement` in core.js returns <5 hits (down from current); all 5 components used by >=3 panels; no visual regression (screenshot diff <2%). (verified: 2026-11-20 - Increment: eliminated all 32 document.createElement calls in core.js (grep count now 0, target <5). Used UI.el(20), UI.msgBubble(2), UI.thinkBlock(1), UI.chip(2), UI.dmSegment(1). Evidence: memory/bui)

2. **API Client Layer** - Create ui/api-client.js: typed wrappers for all /api/* endpoints with error handling, retry logic (exponential backoff, max 3), and response caching (TTL 30s for read-only endpoints). Verified: all existing fetch() calls in core.js replaced with apiClient calls; a simulated 500 triggers retry; cache prevents duplicate requests within TTL. (pointer: memory/builder/api_client_layer_increment1-2026-11-20.md)
   - **PROGRESS 2026-11-20 (increment 1):** `ui/api-client.js` built (150L): DI retry core (exp backoff+jitter, maxRetries=3), TTL-30s GET cache, 17 typed /api/* wrappers, ApiError, UMD export. Static gate PASS (`memory/builder/gate_api_client.py`). Canonical node test authored (`memory/builder/test_api_client.js`) — sandbox has no node runtime, so behavioral run pending a node-capable host. Remaining: wire core.js/uploads.js fetch() calls to apiClient + execute node test. Evidence: memory/builder/api_client_layer_increment1-2026-11-20.md.

3. **Build-Verify-Pin Pipeline** - `python memory/builder/build_verify_pin.py <file>`: (a) validates syntax (JS/HTML/CSS), (b) runs in-process smoke test, (c) if file is pinned, computes sha12 + writes canonical backup, (d) updates PIN_FILES in memory_mirror.py, (e) git commits. Verified: running on a test file produces all 5 steps; a syntax error halts at step (a) with clear message; pin advancement works end-to-end. (pointer: memory/builder/MEMORY.md)
   - **PROGRESS 2026-11-20 (increment 1, verified):** `memory/builder/build_verify_pin.py` built + tested in-process — steps (a) validate / (b) sha12 / (c) canonical copy (`index_html_CANONICAL_95e752e795c0_2026-11-20a.html`, sha-matched) / (d) PIN_FILES line all PASS; broken CSS + unbalanced JS correctly halt at (a). Remaining: `--apply` memory_mirror.py edit + git-commit leg (gated on non-empty mirror vantage — empty in sandbox). Evidence: memory/builder/build_verify_pin_increment1-2026-11-20.md.

4. **Error Boundary System** - Wrap each portal panel in an error boundary: if a panel's render throws, show a styled error card with the exception message + "retry" button instead of crashing the whole page. Verified: injecting a deliberate error into one panel shows the error card; other panels unaffected; retry re-attempts render.
   - **PROGRESS 2026-11-20 (increment 2, verified):** `showPanelError(el, msg, retryFn)` helper added to core.js (line ~21); `.panel-error` CSS block in app.css. All 3 main panel catch blocks wired: actUpdate→actBody, fleetUpdate→fleetBody, opsLoad→gitStatus. Brace/paren balance confirmed. Remaining for full closure: live browser test (kill API → verify fallback cards appear → restart → click retry → panels restore); extend to goals/files panels if needed. Evidence: memory/builder/error_boundary_increment2-2026-11-20.md. (verified: 2026-11-20 - showPanelError helper + CSS .panel-error card implemented; actUpdate/fleetUpdate/opsLoad catch blocks wired to error cards with retry; brace/paren balance verified; evidence: memory/builder/error_boun)

5. **Portal Performance Optimization** - Profile core.js render time per panel; identify >100ms renders; optimize (lazy-init, memoization, DOM batching). Target: initial page load <2s, all panel renders <100ms. Verified: performance.now() measurements show improvement; no visual regression; Lighthouse (or equivalent) score >=80.

6. **State Management Refactor** - Extract portal state (active tab, selected agent, filter values, connection status) into a single ui/state.js module with subscribe/notify pattern. Eliminates global variable sprawl in core.js. Verified: all panel reads go through state.get(); state changes trigger re-render of dependent panels only; no stale-state bugs in 10-minute soak test.

7. **Accessibility Audit + Fix** - Run axe-core (or manual WCAG 2.1 AA checklist) against all portal panels. Fix: missing aria-labels, insufficient contrast, keyboard navigation gaps, focus management. Verified: audit report shows 0 critical violations; tab-through covers all interactive elements; screen reader announces panel changes.

8. **Dark Mode Implementation** - Add a theme toggle (sun/moon icon in header) that switches CSS custom properties between light/dark palettes. Persist preference in localStorage. All components must respect the active theme. Verified: toggle switches all panels; no white-flash on load with dark pref; contrast ratios pass WCAG AA in both themes; preference persists across reloads. (pointer: memory/builder/verify_theme_toggle_2026-11-17.md)

9. **Portal Test Harness** - `python memory/builder/portal_test.py --suite <name>` runs in-process tests against portal endpoints + UI logic: (a) API contract tests (all /api/* return expected shape), (b) UI smoke tests (each panel renders without exception), (c) integration tests (agent message flow end-to-end). Verified: >=20 test cases pass; a deliberately broken endpoint is caught; report written to memory/builder/test-report.md.

10. **Code Quality Gate** - Add a pre-commit hook (or manual `python memory/builder/quality_gate.py`) that checks: no console.log in production code, no unused imports, file size <500 lines per JS/CSS file, all new UI uses components.js. Verified: gate catches a deliberate violation; clean code passes; report lists all violations with file:line.
