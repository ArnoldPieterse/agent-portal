# Builder — Cycle 20 Goals (set 2026-11-26)
> Proposed by **Builder** for the **Fleet Autonomy Convergence** cycle. Fleet is at steady-state (Lv13, 115/115).
> This set moves one level up from Cycle 19's "expose convergence" UI: it makes the convergence **loop itself** autonomous end-to-end, self-validates Builder's own automation, and locks down the data contracts steady-state depends on. UI legs delegate to **Pixel**; gate/perf/deploy legs to **Forge**.
Pillars: (A) Autonomous closeout & loop control, (B) Self-healing of Builder's own automation, (C) Steady-state observability via stable contracts/feeds.

1. **Convergence State-Machine SSOT** - `python memory/builder/convergence_fsm.py`: one authoritative FSM for the convergence lifecycle (DISCOVERING -> CONVERGING -> STEADY-STATE <-> REGRESSING -> RECONVERGING) with a legal-transition table; every mode writer / sentinel / closeout emits through it and illegal transitions are rejected + logged to `fsm-events.jsonl`. Distinct from the existing fleet-mode atomic writer (which only writes atomically, no state validation). Verified: unit tests assert each legal transition is accepted and a seeded illegal one is rejected+logged; `fleet-mode.json` now carries `fsm_state` + `fsm_validated:true`; grep confirms every mode/sentinel writer imports the FSM (no bypass).

2. **Zero-Touch Cycle Closeout Orchestrator** - `python memory/builder/cycle_closeout.py`: run the full UNATTENDED close in one pass — verify 100% via goal_ledger -> archive old goals to `memory/goals/archive/` + `closed_topics.json` -> generate next-cycle seat-drafts (reuse seat_draft_validate) -> emit AWAITING_RATIFICATION -> on ratify, open the new cycle. Chains existing pieces; the new artifact is the end-to-end orchestrator with `--dry-run` preview + idempotency + full audit to `closeout-audit.jsonl`. Verified: dry-run on the current 100% fleet produces the correct archive list + drafts with zero human steps; a live run archives exactly the completed set and opens the next cycle; re-running is idempotent (no double-archive, no duplicate drafts).

3. **Convergence Event Bus (SSE + replay)** - `python memory/builder/event_bus.py`: one append-only bus (`convergence-events.jsonl`) with an SSE endpoint that all convergence writers emit to and all consumers (Pixel panels, Forge gates, Designer gauges) subscribe from; cursor-based replay lets a late-joining panel reconstruct full state. Replaces N bespoke feeds with a single SSOT stream. Verified: a simulated transition is broadcast to 2 subscribers within 2s; a new subscriber at cursor=0 replays all events and reaches current state; a deliberately slow consumer does not drop the source's writes (bounded backpressure). (pointer: memory/builder/convergence_api.py)

4. **Autonomy-Infra Self-Health Probe** - `python memory/builder/infra_health.py`: liveness probe over Builder's own autonomy scripts (mode writer, dispatch filter, status propagator, closeout, FSM) -> `infra-health.jsonl` with `{ok, last_run, latency, error}` per script; a watchdog flags any script that has not run in N cycles or is erroring. Meta-self-healing: the fleet detects when its OWN automation degrades. Verified: probe reports all scripts healthy on clean state; clearing one script's last-run marker causes it to be flagged within 1 cycle; JSONL schema stable for a Pixel widget + Forge gate.

5. **Data-Contract Registry + Lint** - `python memory/builder/contracts.py`: central registry of the cross-lane JSON/JSONL contracts (autoloop.jsonl, fleet-mode.json, assists.jsonl, autonomy-score.json, convergence-events.jsonl, ...) with field names/types/required-set; `--lint` validates live files against the registry and fails on drift with exact path; `--gen-stub` emits mock data for tests. Verified: lint passes on current live files; a seeded missing-field in a copy is caught with its exact dotted path; every contract introduced by this cycle has a registered schema.

6. **Human-Touchpoint Census + Removal Tracker** - `python memory/builder/touch_census.py`: parse the last N cycles' autoloop + intervention logs to enumerate every human touch (unblock / redirect / ratify / approval), classify each as removable-now / removable-later / required, and track removal progress -> `touches.jsonl`. Feeds the Human-Touch Minimizer widget + Orchestrator's autonomy scorecard. Distinct from intervention_logger (which logs raw interventions; this is a cross-cycle census + deterministic removal tracker). Verified: census reproduces a known seeded set of touches; classification is deterministic (same input -> same output); when a removal lands, the count drops on the next cycle's run.

7. **Seat-Draft Autonomy Validator v2** - `python memory/builder/seat_draft_autonomy.py`: score each seat-drafted goal for autonomy-readiness — flag goals that implicitly require a human ("connect account", "approve", "Arnold to..."), estimate removable-touch count, and reject/annotate drafts that would add a new human gate. Pairs with the zero-touch closeout so next-cycle goals are born autonomy-clean. Distinct from seat_draft_validate (quality/feasibility); this adds the human-gate axis. Verified: a draft containing one human-gate goal is flagged on the offending line; a clean draft passes; the score is reproducible across runs.

8. **Convergence Regression Auto-Remediation Dispatcher** - `python memory/builder/regression_dispatcher.py`: when the FSM/sentinel detects REGRESSING, AUTOMATICALLY open exactly one remediation goal in the correct lane, assign it, and track to closure — closing the detect->act loop without a human clicking cycle-19's "open remediation goal" button. Verified: a seeded regression auto-opens exactly one remediation goal in the correct lane within 1 pass; repeated detection opens no duplicate; remediation closure flips the FSM back to CONVERGING/STEADY-STATE.

9. **Model-Swap Convergence Guard** - `python memory/builder/swap_guard.py`: wrap model_swap.py with a convergence-aware pre-flight — block any swap whose target seat has an in-flight goal that downtime would orphan, check VRAM + alias-resolution SLA (pairs Mechanic #8), and emit before/after consistency snapshots for Forge's consistency diff. Prevents a swap from silently breaking convergence. Verified: a swap on a seat with an in-flight goal is blocked with the reason; a clean swap proceeds and emits before/after snapshots that Forge's drift/consistency check consumes; guard logs to `swap-guard.jsonl`.

10. **Steady-State Observability Bundle (delegated)** - integrate goals 3-8 outputs into one steady-state data surface: define the exact field contract Pixel renders (contribution share, assist graph edges, touch trend, FSM state) and Forge gates on; ship a `--selftest` that asserts each feed is present, non-empty, schema-valid, and fresh (<1 cycle old). Verified: selftest passes when all feeds are healthy and fails with the exact missing/stale feed named otherwise; Pixel + Forge consume via the contract in goal #5 (no bespoke parsing); this is Builder's integration leg — UI to Pixel, gate wiring to Forge.
