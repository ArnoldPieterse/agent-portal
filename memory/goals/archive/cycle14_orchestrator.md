# Orchestrator - 10 goals (set 2026-11-23, cycle-14)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 14 makes the fleet operate in a true closed loop: sense -> decide -> act -> verify, with a unified cockpit as the control surface. No human in the loop for routine operations.

1. **Decision Loop Closure Tracker** - `python memory/orchestrator/loop_closure.py`: track every autonomous decision from trigger to verified outcome; compute closure rate and mean time-to-closure per cycle. Emit memory/orchestrator/loop-closure-<date>.json with decisions array, closure_rate, mttc_seconds, unclosed array. Verified: file contains >=5 tracked decisions with complete lifecycle timestamps; closure_rate is a float 0-1; an artificially stuck decision (no outcome recorded) appears in unclosed.

2. **Fleet Cockpit State Aggregator API** - Add `/api/cockpit` endpoint to portal returning unified JSON: agents array (name, model, host, vram_used, vram_max, ctx_used, status), goals object (total, open, reached, at_risk), resources object (total_vram, used_vram, utilization_pct), recent_decisions (latest 20), predictions (top 5 risks). Data sourced from Mechanic probes + goal files + decision log. Verified: GET /api/cockpit returns valid JSON in <500ms; all 8 agents present in agents; goals counts match memory/goals/*.md; a deliberately stale probe is reflected in agent status.

3. **Auto-Escalation Policy Engine** - `python memory/orchestrator/escalation.py`: define escalation rules (auto-remediate if confidence >0.7; escalate to human alert if <0.7 or if 2 consecutive auto-fixes fail); implement decision logic + test with synthetic scenarios. Emit memory/orchestrator/escalation-policy.json (rules, thresholds, test_results). Verified: >=4 escalation rules defined; a synthetic low-confidence scenario triggers escalation alert; a high-confidence scenario triggers auto-remediation without alert; 2 consecutive failures trigger escalation.

4. **Cross-Agent Handoff Protocol** - `python memory/orchestrator/handoff_protocol.py`: implement standard handoff format (from_agent, to_agent, task_id, context, acceptance_criteria, deadline, status); when an agent is unreachable, auto-reassign its open tasks to the next-capable agent per a capability matrix. Emit memory/orchestrator/handoffs-<date>.jsonl. Verified: a handoff from Agent A to Agent B is recorded with all fields; reassignment triggers when source agent is marked unreachable; acceptance criteria are non-empty for every handoff.

5. **Cycle Autonomy Score** - `python memory/orchestrator/autonomy_score.py`: measure % of cycle actions taken autonomously vs requiring human input (from decision log + escalation alerts); track trend across cycles. Emit memory/orchestrator/autonomy-trend.json (array of cycle, autonomous_pct, human_interventions, score). Verified: score computed for current cycle; a cycle with 0 human interventions scores 100%; the trend array has >=2 entries (previous + current).

6. **Decision Replay & Audit Log** - `python memory/orchestrator/decision_replay.py`: record every autonomous decision with full context snapshot (timestamp, trigger, agent_state, fleet_state, decision, action_taken, outcome, confidence); support --replay <decision_id> to show the exact state that led to the decision. Emit append-only memory/orchestrator/decision-log.jsonl. Verified: >=10 decisions logged with all fields populated; replaying a decision shows the pre-decision state; a decision with missing context field is flagged as incomplete.

7. **Fleet Degradation Cascade Simulator** - `python memory/orchestrator/cascade_sim.py`: simulate N agents going down simultaneously (N=1,2,3); verify recovery paths exist for each scenario; emit risk assessment (scenario, affected_goals, recovery_time_estimate, cascade_risk_score). Emit memory/orchestrator/cascade-assessment.json. Verified: 3 scenarios simulated; each shows affected goals and recovery estimate; a scenario where no recovery path exists is flagged as CRITICAL with the missing dependency named.

8. **Cockpit Alert Correlator** - `python memory/orchestrator/alert_correlate.py`: correlate multiple alerts into single incidents (dedup by root-cause signature, group by time window); reduce alert count while preserving signal. Emit memory/orchestrator/incidents-<date>.json (array of incident_id, alerts, root_cause, severity, resolved). Verified: 5 synthetic alerts with same root cause collapse to 1 incident; alerts with different causes remain separate; correlation reduces total alert count by >=30% on test dataset.

9. **Goal Auto-Reprioritization Engine** - `python memory/orchestrator/reprioritize.py`: when a goal is blocked >4h, auto-reprioritize dependent goals (push them back), notify owner via handoff protocol, and log the reprioritization. Emit memory/orchestrator/reprioritizations-<date>.jsonl. Verified: a synthetic blocked goal triggers reprioritization of its dependents; notification is recorded; the blocked goal's deadline is extended by the correct delta; unblocked goals are unaffected.

10. **Autonomous Cycle Completion Report** - `python memory/orchestrator/cycle_report.py`: at cycle end, auto-generate report (cycle, theme, autonomous_actions, human_interventions, goals_reached, goals_missed, incidents, lessons_learned, next_cycle_recommendations). Emit memory/orchestrator/cycle-N-report.md. Verified: report contains all fields; autonomous_actions count matches decision log; a cycle with 100% goals reached shows 0 in goals_missed; recommendations are specific (not generic).
