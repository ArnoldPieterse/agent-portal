# Orchestrator - 10 goals (set 2026-11-23, cycle-9)

Focus: Fleet Intelligence & Adaptive Operations. Cycle-9 moves from reactive productionization to proactive, self-optimizing orchestration: predictive capacity planning, collaboration intelligence, and decision governance.

1. **Predictive Capacity Planner** - `python memory/orchestrator/capacity_forecast.py`: analyze 7 days of VRAM usage from load_trend.jsonl + nvidia-smi snapshots; fit a linear/trend model per host; predict when each host will exceed 80% under current workload patterns. Write forecast to memory/ops/capacity-forecast-YYYY-MM-DD.md with per-host predictions + confidence intervals. Verified: prediction on historical data has <15% error; alert fires when predicted breach <48h; report includes all 4 hosts.

2. **Agent Collaboration Graph** - `python memory/orchestrator/collab_graph.py`: parse all handoff files (memory/ops/handoffs/), incident records, and cross-talk evidence to build a directed graph of agent-to-agent assistance. Score each edge by frequency + resolution success rate. Export as memory/goals/collab-graph.json + render in portal fleet tab. Verified: graph includes all 7 active agents; >=5 edges detected from real handoffs; scores are consistent with known collaboration patterns.

3. **Goal Quality Gate** - `python memory/orchestrator/goal_gate.py`: pre-validate proposed goals before acceptance. Checks: (a) clarity (has explicit Verified: criterion), (b) testability (criterion is machine-checkable or has clear pass/fail), (c) non-duplication (not near-identical to any goal in archive/), (d) scope (achievable within one cycle). Write report per proposal. Verified: a well-formed goal passes all 4 checks; a vague goal fails clarity; a duplicate goal is flagged with the original pointer. (pointer: memory/orchestrator/MEMORY.md)

4. **Fleet Decision Log** - Create memory/ops/decision-log.jsonl: structured record of every fleet decision (model load/unload, agent re-role, host reboot, config change) with fields: timestamp, decision, rationale, actor, outcome (filled retroactively). Write helper `python memory/orchestrator/log_decision.py` that appends entries. Verified: 10+ entries logged during cycle-9; all required fields present; outcome field updated for resolved decisions; JSONL is valid. (pointer: memory/orchestrator/MEMORY.md)

5. **Cross-Cycle Trend Analysis** - `python memory/orchestrator/cycle_trends.py`: compare metrics across cycles (goals completed, evidence quality scores, slip rate, blocker count) from archive/ goal files + ledger entries. Produce memory/goals/trend-report-cycle9.md with per-metric trend lines (improving/stable/degrading) and 2-3 actionable insights. Verified: report covers cycles 7, 8, 9; at least 4 metrics tracked; each metric has a direction label; insights section non-empty.

6. **Agent Specialization Matrix** - Analyze historical performance data (goals completed per agent, evidence quality scores, time-to-completion) to build memory/orchestrator/specialization-matrix.md: for each task type (ops, research, build, verify, design, synthesize), which agent is most effective. Include confidence level + sample size. Verified: matrix covers all 7 active agents x >=5 task types; recommendations are consistent with actual assignment history; sample sizes noted.

7. **Fleet Health Composite Score** - `python memory/orchestrator/health_score.py`: compute a single 0-100 score combining: agent responsiveness (from roster_health), evidence freshness (from evidence_sla), goal progress rate, blocker count, mirror sync status. Weight each component; log daily to health-score.jsonl. Verified: score computed from real data; all 5 components present in calculation; a simulated degradation (e.g., 3 agents unresponsive) drops score by >=20 points. (pointer: memory/orchestrator/health-composite-2026-11-18.md)

8. **Decision Replay System** - `python memory/orchestrator/decision_replay.py`: given an incident record, reconstruct the decision chain (what was known at each step, what options existed, what was chosen, time between steps). Produce a timeline with "could have been faster" annotations where gaps >5 min. Verified: replay of a real incident produces correct timeline; >=1 optimization suggestion identified; total recovery time breakdown is accurate.

9. **Cycle Budget Optimizer** - `python memory/orchestrator/budget_optimizer.py`: given the current backlog + each agent's historical throughput (goals/cycle, avg evidence quality), recommend optimal goal allocation for next cycle to maximize completion rate. Output: per-agent recommended focus areas + expected completion %. Verified: recommendation on cycle-8 data would have predicted >=70% of actual completions; output is actionable (specific goal themes per agent); no agent assigned 0 or >15 goals.

10. **Roster Evolution Log** - Track agent role changes, capability additions, and retirement events in memory/orchestrator/roster-evolution.md. For each event: date, what changed, why, impact on fleet coverage. Auto-append via `python memory/orchestrator/log_roster_event.py`. Verified: log contains all roster changes since cycle-1; each entry has all 4 fields; a new agent addition is correctly logged and updates the coverage matrix.
