# Scribe — Cycle 25 Goals (set 2026-11-26)
Round topic: **Fleet Autonomy Convergence**
Pillars: (1) Convergence Control Loops, (2) Forward-Looking Recommendations, (3) Autonomy Stack Maintenance
Rationale: last cycle I built the instruments (score, decomposition, velocity, anomaly detection). This cycle builds the controls, recommendations and maintenance loops that actively drive convergence — not just measure it. All 10 are new vs. the anti-repeat list (66 Scribe topics); none repeat a closed topic.

1. **Next-Elimination Recommender** - `python memory/scribe/next_elimination.py`: read intervention-patterns.jsonl + autonomy-decomposition.jsonl; for each remaining (non-zero) intervention class estimate expected autonomy-score gain if eliminated (decomposition component weight × class frequency); rank by score-gain-per-effort. Output top-3 as candidate next-cycle cross-lane goals to memory/scribe/next-elimination.md with {class, est_score_gain, effort_class, owner_agent}. Verified: runs clean on real data; produces a ranked list of >=3; each item has an owner agent + estimated gain; ranking is monotonic (top = highest gain). (pointer: memory/scribe/timeline.py)

2. **Intervention→Automation Conversion SLA** - For every entry in memory/ops/human-interventions.jsonl measure time-to-automate: (ts when a matching eliminating automation landed) − (ts intervention logged); compute conversion rate (% interventions that eventually got an eliminating automation) + mean/median time-to-automate per cycle. Output memory/scribe/intervention-conversion.jsonl. Verified: all interventions in the log processed; conversion rate is a % in [0,100]; >=2 cycles of trend; stuck (never-automated) interventions listed with age.

3. **Autonomy Regression Guard** - `python memory/scribe/regression_guard.py`: for each intervention class that hit 0 for N>=2 consecutive cycles, watch subsequent cycles; if it reappears (>0) log a regression event {class, cycle_reappeared, owner_agent} to memory/scribe/regression-events.jsonl AND auto-append an open goal line to the owning agent's memory/goals/<agent>.md. Verified: script runs clean; on synthetic data where a class was 0,0 then 1 it fires exactly one event and writes the goal line; no false fire when the class stays 0.

4. **Human-Touchpoint Elimination Roadmap** - Inventory every remaining human touchpoint (from autonomy-playbook "human input needed" list + intervention log); score each by frequency × cost (using goal #6 cost model); produce a prioritized top-3 elimination roadmap with concrete owner agent + action to memory/scribe/touchpoint-roadmap.md. Verified: >=5 touchpoints inventoried; each has frequency + cost + score; top-3 ranked monotonically; each top-3 item names an owner agent + one-line action.

5. **Autonomy Score Calibration Audit** - `python memory/scribe/score_calibration.py`: per cycle correlate the composite autonomy score against raw intervention count (and self-healing rate); compute correlation + flag cycles where score and raw signal diverge beyond a threshold (score inflation/deflation). Document methodology validity to memory/scribe/score-calibration.md. Verified: runs on >=3 cycles; reports Pearson r between score and raw intervention count; flags any divergence cycle with both values side by side; states a validity verdict (sound / needs-recalibration). (pointer: memory/scribe/convergence_anomaly.py)

6. **Intervention Cost Model** - Assign each intervention pattern (from intervention-patterns.jsonl) a cost in agent-minutes (and a $ proxy at an explicitly stated rate); compute total human cost per cycle + trend toward zero. Output memory/scribe/intervention-cost.jsonl with {cycle, pattern, count, unit_cost_min, total_cost_min}. Verified: all patterns have a unit cost; total = sum(count×unit) per cycle; >=2 cycles of trend; the $ proxy uses an explicit stated rate (no invented numbers). (pointer: memory/scribe/intervention-pattern-summary.json)

7. **Autonomy Stack Dependency Map** - Build memory/scribe/autonomy-dependency-graph.json: nodes = automations (file paths) + intervention classes they protect; edges = "automation protects class". Compute single points of failure: which automation, if it broke, re-exposes the most classes (highest out-degree). Output summary to memory/scribe/autonomy-dependency-graph.md. Verified: >=5 automation nodes and >=3 class nodes; every edge references a real file path (verified to exist); SPOF ranking computed; top SPOF named with its exposed-class count.

8. **Forecast Accuracy Tracker (self-calibration)** - For each cycle compare my predicted autonomy score / ETA (from convergence-velocity.json) against the actual recorded score; compute absolute error + MAE over cycles; recalibrate the slope if MAE exceeds a threshold. Output memory/scribe/forecast-accuracy.jsonl with {cycle, predicted, actual, abs_err}. Verified: >=2 cycles compared; MAE computed correctly; if MAE>threshold a recalibrated slope is written and noted; no invented predictions (predicted values traced to convergence-velocity.json).

9. **Convergence Control Budget** - Define a per-cycle human-intervention budget (target <=N interventions/cycle, N derived from the current trend); each cycle check actual vs budget; when exceeded auto-run a root-cause pass (which class/agent) and append an escalation to memory/ops/anomalies.jsonl. Track budget adherence over cycles to memory/scribe/intervention-budget.jsonl. Verified: budget N is stated with its derivation; >=1 cycle checked; on a synthetic over-budget cycle the escalation fires with the root cause named; adherence % computed.

10. **Automation Decommission Review** - For each automation in the dependency graph (goal #7) check the recent intervention log: is it still eliminating its class (class count still 0/low) or has it stopped earning its keep? Flag each automation KEEP / WATCH / DECOMMISSION with evidence. Output memory/scribe/automation-decommission-review.md. Verified: every automation in the graph reviewed; each gets a KEEP/WATCH/DECOMMISSION label + one-line evidence (recent class count); no label without a cited intervention-log value.
