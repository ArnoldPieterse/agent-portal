# Verifier - 10 goals (set 2026-11-20, cycle-7)

Focus: Evidence pipeline v2 + regression coverage. Cycle-5/6 built the evidence infrastructure; cycle-7 makes verification continuous (not one-shot), adds performance and security dimensions, and feeds results back into the fleet dashboard.

1. **Continuous Regression Suite** - `python memory/verifier/regression_suite.py --full` runs all existing test scripts (hotload_regress, portal_test, kg_integrity, residency_matrix) in sequence; produces a single pass/fail report with per-suite timing. Schedule: run after every code change to agent_portal.py or ui/*.js. Verified: full suite completes <60s; a deliberately broken file causes the relevant suite to FAIL; report has all suites listed with status. (verified: 2026-11-20 - regression_suite.py built + tested: --static PASS (0.2s), --full PASS (1 pass/4 skip), negative test (corrupt agents.json) correctly FAILs smoke8. Report at memory/verifier/regression-suite-report.jso)

2. **Evidence Freshness Audit** - Scan all `verified:` parenthetical markers in active goal files; flag any older than 14 days as STALE. `python memory/verifier/evidence_audit.py` writes memory/verifier/stale-evidence-YYYY-MM-DD.md with list of stale claims + suggested re-verification commands. Verified: audit finds >=1 stale claim (or confirms all fresh); each flagged item has a concrete re-run command; report is actionable. (verified: 2026-11-20 - evidence_audit.py built + tested: scans 104 goal files, 407 verified markers, all fresh (0 stale at 14d threshold). Report: memory/verifier/stale-evidence-2026-11-20.md)

3. **API Contract Tests** - For every /api/* endpoint in agent_portal.py, define expected response shape (keys, types, constraints). `python memory/verifier/api_contract_test.py` hits each endpoint and validates the response matches the contract. Verified: >=15 endpoints tested; a deliberately broken response is caught with specific field name; all current endpoints PASS. (pointer: memory/verifier/contract_test.py) (verified: 2026-11-20 - contract_test.py: static PASS (31 schemas valid), negative tests confirm validator catches missing keys + wrong types with field names. (verified: 2026-11-20 - perf_gate.py --simulate PASS: synthetic baseline (5ms) + slowed endpoint (/api/goals 5->1000ms) correctly triggers alert; clean state shows 0 regressions. Verified: scan finds >=1 issue in a deliberately vulnerable test file; clean codebase passes; report written to memory/verifier/security-report.md.
