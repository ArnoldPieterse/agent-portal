# Orchestrator - 10 goals (set 2026-11-23, cycle-13)

Focus: Production Hardening & Self-Sustaining Operations. Cycle 13 proves the autonomy layer works under stress and makes fleet governance self-sustaining.

1. **Fleet Health Auto-Audit Loop** - `python memory/orchestrator/fleet_audit.py`: on each auto-loop pass, run a structured audit: (a) all 8 agents respond to ping within 30s, (b) /api/goals returns valid JSON with correct counts, (c) no goal file has >2 open goals without evidence for >48h, (d) memory/INDEX.md pointers resolve. Emit memory/orchestrator/audit-<date>.json with pass/fail + failures list + actions_taken. Verified: 3 consecutive passes produce valid audit files; a deliberately broken pointer is detected and flagged in failures[].

2. **Incident Drill Orchestrator** - `python memory/orchestrator/incident_drill.py`: define a drill sequence (e.g., "simulate host Black unreachable for 5 min") and orchestrate: trigger -> wait for Mechanic detection -> verify remediation policy fires -> confirm recovery -> score the drill. Output: memory/orchestrator/drill-results.jsonl (one line per drill with triggered_at, detected_at, remediating_at, recovered_at, score). Verified: 2 drills executed end-to-end; detection latency < 120s in both; scores logged.

3. **Token Budget Governor** - `python memory/orchestrator/token_budget.py`: track per-agent token consumption from portal logs; enforce soft budget (warn at 80%) and hard cap (pause agent at 100%); emit daily summary to memory/orchestrator/token-report-<date>.md. Verified: report shows per-agent tokens for last 24h; a simulated over-budget agent is flagged with recommended action; JSON output is machine-readable.

4. **Goal Quality Gate** - `python memory/orchestrator/goal_gate.py`: before accepting new goals into a cycle, run quality checks: (a) no duplicate of closed_topics.json entries (fuzzy match >80% similarity), (b) each goal has a concrete verification command, (c) goals are independent (no circular dependencies), (d) total is 10 per agent. Emit pass/fail report. Verified: submitting a goal that duplicates a closed topic is rejected with the matching entry cited; a goal without a verification command is flagged.

5. **Fleet Capacity Dashboard API** - Add `/api/capacity` endpoint to portal: returns agents array (name, model, vram_used, vram_max, ctx_used, ctx_max, status) + fleet totals (total_vram_used, total_vram_max, utilization_pct, predicted_breach_eta). Data sourced from Mechanic probes + model_router output. Verified: endpoint returns valid JSON; values match actual model load state within 5%; breach ETA is null when no breach predicted.

6. **Auto-Loop Efficiency Report** - `python memory/orchestrator/loop_efficiency.py`: analyze the last N auto-loop passes (from portal logs): count agent turns, tool calls, file writes, goal closures per pass; compute "useful work rate" = (goal_closures + evidence_writes) / total_turns. Emit memory/orchestrator/loop-efficiency-<date>.md with trend line (improving/flat/degrading). Verified: report covers >=5 passes; useful work rate is computed; a pass where an agent produced 0 file changes is flagged as "low-yield".

7. **Cross-Agent Handoff Protocol** - Define and test the handoff mechanism: when agent A completes work that agent B needs, emit a structured handoff note (memory/handoffs/<date>-<from>-to-<to>.md) with context, artifact_path, acceptance_criteria, deadline. Verified: 3 handoff notes created in this cycle; each recipient agent's next pass reads and acts on the note; protocol documented in memory/ops/handoff-protocol.md.

8. **Fleet State Snapshot & Restore** - `python memory/orchestrator/fleet_snapshot.py`: capture full fleet state (goal files, KB index hash, model assignments, portal config) to a timestamped snapshot file; provide --restore <snapshot_id> to roll back. Verified: snapshot taken; a goal file is modified; restore brings it back byte-identical; snapshot list shows >=2 entries after 2 captures.

9. **Agent Performance Scorecard** - `python memory/orchestrator/scorecard.py`: for each agent, compute weekly score: goals_reached/total, avg_turns_per_goal_closure, evidence_quality (spot-check 3 evidence leaves per agent), cross-agent_assist_count. Emit memory/orchestrator/scorecard-<week>.md. Verified: all 8 agents have scores; an agent with 0 closures in the period is flagged; scorecard is sortable by any metric.

10. **Cycle Closure Report** - `python memory/orchestrator/cycle_report.py`: at cycle end, auto-generate a closure report: goals reached per agent, key artifacts produced, incidents encountered, lessons learned (extracted from OPS-NOTES), recommendations for next cycle. Emit memory/orchestrator/cycle-<N>-report.md. Verified: report generated for cycle 12; contains all 4 sections; artifact paths in report are resolvable.
