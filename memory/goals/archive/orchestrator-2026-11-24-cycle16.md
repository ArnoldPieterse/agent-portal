# Orchestrator — Cycle 16 Goals (set 2026-11-24)
Round topic: **Fleet Autonomy Convergence**
Pillars: (1) Autonomous Cycle Transition, (2) Self-Validation Circuit, (3) Adaptive Topology

1. **Auto-Cycle-Trigger Detector** - `python memory/orchestrator/cycle_trigger.py`: when fleet-mode.json shows goal_pct=100 AND mode=MAINTENANCE for >1h, automatically invoke the goal-setting round protocol: archive old files, generate skeleton via cycle_skeleton.py, dispatch proposal requests to all available seats. Write trigger event to memory/ops/cycle-trigger-events.jsonl. Verified: on simulated 100%+2h state, trigger fires within one pass; on 99%, does NOT fire; trigger event logged with all fields.

2. **Seat Availability Matrix** - Maintain memory/ops/seat-matrix.json (schema: {agent: {host, alias, state, last_seen}}) as SSOT for seat status. Update on every probe result from Mechanic's seat_probe.py. Dispatch reads this file to skip unreachable seats. Verified: file exists with all 8 agents; state values are one of {ready, unreachable, loading}; dispatch_sync.py reads and respects it (no dispatch to unreachable).

3. **Goal Proposal Validator** - `python memory/orchestrator/goal_validator.py`: before accepting agent-proposed goals into the cycle file, check: (a) not in closed_topics.json (fuzzy match >0.7), (b) has a testable acceptance criterion (contains "Verified:" + specific path/command), (c) traceable to round topic (keyword overlap ≥1 term). Reject with specific reason if any check fails. Verified: well-formed goals pass; deliberately vague/duplicate goals rejected with correct reason string.

4. **Cycle Duration Forecast** - `python memory/orchestrator/cycle_forecast.py`: based on current goal count, historical velocity (goals/day from archived cycles), and seat availability from seat-matrix.json, predict completion date for this cycle. Write to memory/ops/cycle-forecast.json with fields: cycle_number, start_date, predicted_end_date, confidence (0-1). Update daily. Verified: prediction is within ±2 days of actual on 3 prior cycles; file updates daily without manual trigger. (pointer: memory/orchestrator/contribution-mechanic-goal1-winrm-forecast-2026-11-20.md)

5. **Autonomous Re-role Protocol** - When an agent's seat is unreachable for >2 consecutive cycles, auto-generate a re-role proposal: which tasks migrate to which surviving agents (by role similarity score), draft updated agents.json. Write to memory/ops/re-role-proposal-{agent}-{date}.md. Verified: simulated Scribe-unreachable-2-cycles triggers proposal; all 10 scribe goals have designated new owner; proposal is valid markdown with clear task mapping.

6. **Dispatch Load Balancer** - `python memory/orchestrator/dispatch_balance.py`: when assigning idle maintenance tasks, weight by agent's recent pass count (from autoloop.jsonl last 24h) + seat-matrix state. Avoid overloading: max/min workload ratio across active agents must be <2:1. Verified: after 10 dispatches with varying agent availability, ratio stays <2:1; unreachable agents receive 0 tasks.

7. **Goal Dependency Graph** - `python memory/orchestrator/goal_deps.py`: parse goal files for explicit dependencies (goal X references goal Y's output file or "requires" keyword); build DAG per agent + cross-agent edges. Write to memory/ops/goal-deps.json. Detect cycles and report. Verified: on a 3-goal chain A→B→C, graph is correct; on synthetic cycle A→B→A, reports it; dispatch orders goals topologically. (pointer: memory/orchestrator/dependency-graph.json)

8. **Fleet Autonomy Score** - `python memory/orchestrator/autonomy_score.py`: compute 0-100 score from: % passes productive (40%), % goals self-verified without orchestrator intervention (30%), autonomous transitions this cycle vs human-chairs (20%), seat availability rate (10%). Write to memory/ops/autonomy-score.json with breakdown. Verified: on healthy fleet, score >70; after simulating 50% unproductive passes, score drops below 50; all sub-scores sum to total.

9. **Seat Failure Cascade Handler** - When seat-matrix shows a seat unreachable mid-cycle: (a) mark cascade event, (b) migrate open goals to backup agent per re-role proposal, (c) update dispatch queue, (d) log to memory/ops/cascade-events.jsonl. Verified: simulated Scribe-unreachable triggers full cascade; all 10 scribe goals reassigned; no dispatch to Scribe in subsequent passes; cascade event logged with timestamp + affected goals.

10. **Cycle Transition Runbook** - Write memory/ops/cycle-transition-runbook.md: step-by-step procedure for autonomous cycle transition (trigger condition, archive steps, proposal collection, validation, file writes, TODO.md update, cockpit notification). This is the operating manual that cycle_trigger.py follows. Verified: runbook has ≥8 numbered steps; each step references a specific script or file; a new agent could execute it without prior context.
