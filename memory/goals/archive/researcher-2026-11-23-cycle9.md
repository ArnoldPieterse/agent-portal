# Researcher - 10 goals (set 2026-11-23, cycle-9)

Focus: Fleet Intelligence & Adaptive Operations. Cycle-9 builds the knowledge layer: a structured semantic graph over fleet state, predictive research patterns, and automated knowledge maintenance.

1. **Fleet Knowledge Graph** - `python memory/researcher/knowledge_graph.py`: extract entities (hosts, models, agents, services, files) and relationships from all memory/**/*.md leaves. Build a lightweight graph (nodes + edges with types). Export as memory/researcher/knowledge-graph.json. Verified: >=50 nodes, >=100 edges; all 4 hosts present; entity types are consistent; JSON is valid and <2MB. (pointer: memory/researcher/kg_integrity_bug_check.py)

2. **Anomaly Detection on Fleet Events** - `python memory/researcher/anomaly_detect.py`: analyze temporal patterns in fleet events (from decision-log.jsonl, incident records, load_trend.jsonl). Use z-score or IQR method to flag anomalous data points. Write alerts to memory/ops/anomalies-YYYY-MM-DD.md. Verified: on historical data, >=3 known anomalies are detected; false positive rate <20%; report includes severity + suggested investigation.

3. **Prediction Accuracy Tracker** - `python memory/researcher/prediction_tracker.py`: parse all forecast files in memory/goals/ (those with "forecast" in name), extract predicted outcomes, compare against actual results where available. Score accuracy per agent. Write to memory/researcher/prediction-accuracy-YYYY-MM-DD.md. Verified: >=10 predictions scored; accuracy % computed per agent; most accurate agent identified; report includes both hits and misses.

4. **Semantic Search Index** - `python memory/researcher/semantic_index.py`: build a lightweight TF-IDF (or simple embedding) index over all memory/ leaves. Support query by natural language topic, return top-5 relevant leaves with relevance scores. Verified: query "model loading failures" returns the correct hotload-related leaves in top 3; query "CSS theme" returns design-related leaves; index builds in <30s. (pointer: memory/researcher/a4a5-crossseat-verify-r39b-2026-11-14.md)

5. **Knowledge Decay Model v2** - Extend freshness scoring with content-type-specific decay rates: ops runbooks decay slowly (90d half-life), performance data decays fast (7d), research findings medium (30d). `python memory/researcher/decay_v2.py`. Verified: a 10-day-old perf report scores lower than a 10-day-old runbook; decay rates are configurable; report includes per-category breakdown.

6. **Research Gap Analysis** - `python memory/researcher/gap_analysis.py`: scan all goal files for topics mentioned but lacking supporting research leaves (no evidence, no pointer to research). Flag gaps with severity (blocking vs nice-to-have). Write to memory/ops/research-gaps-YYYY-MM-DD.md. Verified: >=3 gaps identified from cycle-9 goals; each gap has a suggested research query; severity classification is consistent. (pointer: memory/researcher/MEMORY.md)

7. **Evidence Source Reliability Score** - Track which evidence sources (agent names, file patterns) produce the most reliable findings over time. `python memory/researcher/source_reliability.py`: for each source type, compute: accuracy rate, staleness rate, contradiction rate. Verified: >=3 source types scored; a deliberately unreliable source scores low; report includes confidence intervals. (pointer: memory/researcher/evidence-source-scorer-2026-11-18.md)

8. **Temporal Pattern Mining** - `python memory/researcher/temporal_patterns.py`: find recurring temporal patterns in fleet events (e.g., "mirror drift follows host sleep within 2h", "VRAM spikes correlate with model loads"). Use simple co-occurrence + lag analysis. Write findings to memory/researcher/temporal-patterns.md. Verified: >=3 patterns discovered; each has frequency + confidence; at least 1 pattern is actionable (predictive).

9. **Knowledge Consolidation Pipeline** - `python memory/researcher/consolidate.py`: detect near-duplicate knowledge leaves (same topic, different dates/phrasing). Propose merges with a canonical version + supersession chain. Write merge proposals to memory/ops/consolidation-proposals-YYYY-MM-DD.md. Verified: >=5 duplicate pairs identified; each proposal has both source paths + suggested merged content; no false positives on clearly distinct topics.

10. **Fleet State Snapshot & Diff** - `python memory/researcher/state_snapshot.py`: capture a structured snapshot of fleet state (agents, models, hosts, active goals, open blockers) as JSON. On each run, diff against previous snapshot and highlight changes. Write to memory/researcher/state-snapshots/ + diff report. Verified: two consecutive runs produce correct diff; a simulated change (e.g., new agent added) is detected; snapshots are valid JSON <100KB.
