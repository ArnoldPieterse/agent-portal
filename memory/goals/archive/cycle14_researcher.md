# Researcher - 10 goals (set 2026-11-23, cycle-14, seat-drafted by Orchestrator: Researcher unreachable)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 14 makes the intelligence layer close the loop: every decision is evidence-backed, every prediction is verified against outcomes, and the knowledge graph feeds the cockpit in real time.

1. **Decision Evidence Chain Builder** - `python memory/researcher/evidence_chain.py`: for each auto-decision in the decision log, build the evidence chain that led to it (decision_id, evidence_leaves, confidence, gaps); flag decisions with <2 supporting evidence leaves or any gap severity >0.3. Emit memory/researcher/evidence-chains-<date>.json. Verified: >=5 decisions have complete chains; a decision with 0 evidence leaves is flagged as UNSUPPORTED; chain includes source + timestamp for each leaf.

2. **Prediction Loop Closure Verifier** - `python memory/researcher/prediction_verify.py`: compare predictions made by forecast engine (memory/goals/next10.json) vs actual outcomes from closed goals; compute accuracy metrics (total_predictions, correct, wrong, accuracy_pct, brier_score) per prediction type (ETA, completion, risk). Emit memory/researcher/prediction-accuracy-<date>.json. Verified: >=5 predictions compared; Brier score computed correctly (manual check on 2); a deliberately wrong prediction is counted in wrong; accuracy trend is tracked across cycles.

3. **Knowledge Staleness Cascade Detector** - `python memory/researcher/staleness_cascade.py`: when a KB fact goes stale (>30 days unverified), identify all goals and decisions that depend on it (via citation graph); emit impact report (stale_fact, dependent_goals, dependent_decisions, risk_level). Emit memory/researcher/staleness-impact-<date>.json. Verified: a deliberately aged fact triggers detection; its dependent goals are listed correctly; risk_level is HIGH if >3 goals depend on it; cascade does not false-positive on non-dependent items.

4. **Cross-Cycle Learning Extractor** - `python memory/researcher/cycle_learning.py`: extract patterns from completed cycles (goal completion rates by type, slip causes, incident frequency trends); feed structured findings into next cycle's goal proposals as constraints. Emit memory/researcher/cycle-patterns.json (cycles_analyzed, patterns, constraints_for_next_cycle). Verified: >=3 cycles analyzed; at least 1 pattern is quantitative (e.g., goal type X slips 20% more than average); constraints are actionable (not just observations).

5. **Evidence Confidence Propagation** - `python memory/researcher/confidence_prop.py`: implement confidence scoring that propagates through knowledge graph: if source A (confidence 0.9) supports fact B, B gets min(0.9, base_confidence * decay_factor); compute transitive confidence for all facts. Emit memory/researcher/confidence-map.json (fact_id mapped to base, propagated, source_chain). Verified: a fact with 2 independent sources has higher propagated confidence than 1; a chain of 3 propagations shows decreasing confidence; circular references are detected and flagged.

6. **Anomaly Detection in Fleet Telemetry** - `python memory/researcher/telemetry_anomaly.py`: monitor fleet metrics (token usage, response times, error rates) for anomalies using z-score >2 threshold over rolling 7-day window; emit anomaly report (timestamp, metric, value, expected_range, severity). Emit memory/researcher/anomalies-<date>.jsonl. Verified: a synthetic spike in token usage is detected within 1 pass; normal variation (z<2) is not flagged; >=3 metrics monitored; false positive rate <10% on baseline data.

7. **Decision Quality Scorecard** - `python memory/researcher/decision_quality.py`: score past auto-decisions on: timeliness (trigger-to-action time), correctness (outcome was desired), cost-effectiveness (tokens spent vs value of fix); emit per-decision scores + trend. Emit memory/researcher/decision-scores-<date>.json. Verified: >=10 decisions scored; a correct+fast decision scores >80; a slow+wrong decision scores <40; trend shows improvement or regression over time with direction indicator.

8. **Knowledge Graph Completeness Audit** - `python memory/researcher/kg_completeness.py`: measure % of goal-relevant topics that have adequate KB coverage (>=2 evidence leaves with confidence >0.7); identify gaps ranked by goal-dependency weight. Emit memory/researcher/kg-gaps-<date>.json (total_topics, covered, uncovered, gap_ranking). Verified: >=20 topics assessed; a topic with 0 evidence is in uncovered; gap_ranking is ordered by number of dependent goals; coverage % computed correctly.

9. **Forecast Engine Calibration Loop** - `python memory/researcher/forecast_calibrate.py`: auto-adjust forecast model parameters (decay rates, confidence thresholds) based on recent prediction errors; emit calibration report (parameters_before, parameters_after, error_reduction_pct). Emit memory/researcher/calibration-<date>.json. Verified: after calibration on a dataset with known bias, prediction error decreases; parameters are bounded (no runaway values); calibration is idempotent (running twice gives same result).

10. **Incident Pattern Library** - `python memory/researcher/incident_patterns.py`: build a library of past incidents (id, category, root_cause, resolution, recurrence_count); implement pattern matching: given new incident symptoms, return top-3 matching historical patterns with similarity score. Emit memory/researcher/incident-library.json + match function. Verified: >=5 incidents in library; a new incident with known symptoms matches the correct historical pattern (top-1); similarity scores are ordered correctly; an entirely novel incident returns low-confidence matches (<0.5).
