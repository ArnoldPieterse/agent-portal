# Verifier - 10 goals (set 2026-11-23, cycle-14)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 14 verifies that the autonomy loop is truly closed (detect→diagnose→remediate→verify→update, no human in the loop) and that the cockpit reflects live fleet state accurately and accessibly.

1. **Autonomous Remediation E2E** - `python memory/verifier/remediation_e2e.py`: inject a fault (corrupt a JSON file, kill a process), then verify the full closed loop completes autonomously within SLA: detection fires → diagnosis emitted → remediation executes → post-remediation state verified healthy. No human step required. Emit memory/verifier/remediation-e2e-<date>.json with per-stage timestamps. Verified: 3 fault types tested; each completes the full loop <5min; a deliberately broken remediation script causes the loop to flag STUCK (not silently pass).

2. **Cockpit Live-Staleness Monitor** - `python memory/verifier/cockpit_staleness.py`: on each pass, fetch /api/fleet/cockpit and compare its embedded timestamp against wall clock; if data is >5min old, emit an alert leaf to memory/verifier/staleness-alert-<date>.md. Also track staleness history in cockpit-staleness.jsonl. Verified: runs in <10s; a simulated 6-min-old response triggers alert; a fresh (<1min) response does NOT trigger; 3 consecutive runs logged.

3. **Autonomy Stall Detector** - `python memory/verifier/stall_detector.py`: scan recent auto-loop passes (from decision-log + file mtimes); flag any agent that produced zero file changes across 3 consecutive passes as STALLED. Emit stall report to memory/verifier/stall-report-<date>.md with per-agent status + last-active timestamp. Verified: an agent with 3 no-op passes is flagged; an agent with 1 file change in the window is NOT flagged; report includes all 8 agents.

4. **Closed-Loop Latency Budget** - `python memory/verifier/latency_budget.py`: for each completed autonomy cycle (from decision-log), measure per-segment latency: event→detection, detection→dispatch, dispatch→work-start, work→verify, verify→dashboard-update. Store in latency-budget.json; alert if any segment exceeds its budget (default: 5min per segment, 25min total). Verified: >=3 cycles measured; a deliberately delayed segment is detected and alerted; budget values are configurable in a JSON config file.

5. **Cockpit UI Playwright Gate** - `python memory/verifier/cockpit_ui_test.py`: automated browser test (Playwright or equivalent): load the cockpit page at 768px, 1024px, and 1400px; verify all panels render with non-empty data; check no JS console errors; verify interactive elements (tabs, buttons) are clickable. Emit cockpit-ui-test-<date>.json. Verified: 3 viewports tested; a deliberately hidden panel causes FAIL; no false positives on intact UI; runs in <60s.

6. **Failure Replay Harness** - `python memory/verifier/failure_replay.py`: parse decision-log for recorded failure scenarios (goal + symptom + fix applied); re-execute the same pre-fix state and verify the applied fix prevents recurrence. Emit replay-report-<date>.md with pass/fail per scenario. Verified: >=5 historical failures replayed; a scenario where the fix was reverted is flagged as REGRESSION; a scenario where the fix still holds passes cleanly.

7. **Goal Lifecycle Audit** - `python memory/verifier/lifecycle_audit.py`: trace each goal through its full lifecycle (proposed → assigned → worked → verified → closed) using timestamps from goal files + ledger entries; flag any goal stuck in one state >48h or with a missing transition. Emit lifecycle-audit-<date>.md. Verified: all active goals traced; a deliberately backdated goal (stuck 72h in 'worked') is flagged; no false positives on normally-progressing goals.

8. **Fleet Health Closed-Loop Test** - `python memory/verifier/health_loop_test.py`: simulate fleet health degradation (lower a host's reported VRAM or mark a model as OOM); verify the full autonomous chain fires: threshold breach detected → alert emitted → diagnosis produced → remediation attempted → post-remediation state verified → resolution logged. Emit health-loop-test-<date>.json. Verified: 2 degradation scenarios tested; both complete the chain autonomously <10min; a scenario where remediation fails correctly escalates (not silently swallowed).

9. **Cockpit A11y Gate (WCAG AA)** - `python memory/verifier/cockpit_a11y.py`: automated accessibility check on cockpit panels: verify all interactive elements are keyboard-navigable (tab order), contrast ratios meet WCAG AA (4.5:1 for text, 3:1 for UI components), ARIA labels present on icon-only buttons, focus visible on all focusable elements. Emit cockpit-a11y-<date>.md with per-panel pass/fail. Verified: >=5 panels checked; a deliberately low-contrast element is flagged; keyboard traversal reaches all interactive elements in correct order.

10. **Autonomy Precision/Recall Tracker** - `python memory/verifier/autonomy_metrics.py`: from decision-log, classify each autonomous action as CORRECT (resolved the issue), FALSE-POSITIVE (acted on non-issue), or FALSE-NEGATIVE (missed a real issue that was later caught manually). Compute precision and recall weekly. Emit autonomy-metrics-week<N>.md. Verified: >=10 actions classified; precision and recall computed with correct denominators; a deliberately misclassified action changes the metric as expected.
