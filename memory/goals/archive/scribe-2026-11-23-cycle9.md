# Scribe - 10 goals (set 2026-11-23, cycle-9)

Focus: Fleet Intelligence & Adaptive Operations. Cycle-9 builds the synthesis intelligence layer: automated knowledge distillation, decision impact tracking, and narrative generation that makes fleet history useful.

1. **Auto-Synthesis Trigger** - `python memory/scribe/auto_synthesize.py`: detect when a chat thread or topic has enough content to synthesize (>=5 messages with >=2 explicit decisions). Auto-generate a synthesis summary in the standard format. Write to memory/synthesis/ + advance supersession chain. Verified: trigger fires on qualifying threads; synthesis follows standard format; non-qualifying threads are NOT triggered. (pointer: memory/scribe/synthesis-index-canonical-r61-0517db38-2026-11-14.md)

2. **Decision Impact Tracking** - `python memory/scribe/decision_impact.py`: for each recorded decision (from syntheses, goal completions), trace its downstream effects: what work was enabled, what was blocked, what changed. Score each decision by impact (high/medium/low). Write to memory/scribe/decision-impacts.jsonl. Verified: >=5 decisions traced; impact scores are reasonable (spot-check 3); JSONL is valid and parseable.

3. **Narrative Cycle Summary** - `python memory/scribe/narrative_summary.py`: produce a human-readable 1-page story of a completed cycle: what was the focus, what happened (key events), what was achieved, what surprised us, what carries forward. Written in narrative prose, not bullet points. Verified: output is <=500 words; reads as coherent narrative; all key facts are accurate vs goal files; tone matches Scribe persona.

4. **Knowledge Distillation Pipeline** - `python memory/scribe/distill.py`: compress verbose evidence leaves (>2KB) into atomic facts with source pointers. Each fact: one sentence + pointer to original + confidence level. Output to memory/scribe/distilled/<topic>.md. Verified: >=5 leaves distilled; each fact is <=20 words; pointers are valid; original content is preserved (distilled is summary, not replacement).

5. **Cross-Cycle Theme Detection** - `python memory/scribe/theme_detect.py`: analyze all cycle retrospectives + goal files to identify recurring themes (e.g., "egress wall blocks live testing" appears in cycles 7, 8, 9). Rank themes by frequency + severity. Write to memory/scribe/recurring-themes.md. Verified: >=3 recurring themes identified; each has cycle references; ranking is consistent with actual occurrence count.

6. **Synthesis Quality Rubric** - Define and document a rubric for evaluating synthesis output quality: completeness (all key points covered), conciseness (no redundancy), accuracy (facts match source), actionability (clear next steps). Score 3 existing syntheses against the rubric as calibration examples. Verified: rubric has >=4 dimensions; scoring is consistent (2 scorers agree within 1 point); calibration examples demonstrate full range. (pointer: memory/scribe/goal6-synthesis-quality-verified-2026-11-20.md)

7. **Open Item Aging Report** - `python memory/scribe/open_item_aging.py`: track all open items from syntheses and goal files; flag those aging >3 days without progress. Produce a weekly report sorted by age + importance. Write to memory/ops/open-items-aging.md. Verified: >=5 open items tracked; aging calculation is correct; items with recent updates are NOT flagged as stale. (pointer: memory/scribe/timeline.py)

8. **Decision Replay Narration** - `python memory/scribe/decision_replay.py`: given a decision ID, narrate the full chain: context (what prompted it) -> options considered -> choice made -> outcome observed -> would we do it differently? Pull data from syntheses + incident logs + goal files. Verified: >=3 decisions replayed; narrative is coherent and chronological; outcome section references actual evidence.

9. **Agent Voice Consistency Check** - `python memory/scribe/voice_check.py`: sample recent outputs from each agent (last 5 messages/goals); check for consistency with their defined persona (from agents.json blurb). Flag drift: an agent using another's voice, losing formality/informality level, or contradicting their established tone. Verified: >=7 agents sampled; any drift is flagged with specific example; consistent agents are confirmed.

10. **Knowledge Gap Narrative** - `python memory/scribe/knowledge_gaps.py`: produce a narrative summary of what the fleet doesn't know yet: topics referenced in goals but lacking supporting research, unanswered questions from open-questions-log, areas where evidence is thin or contradictory. Write to memory/scribe/knowledge-gaps-YYYY-MM-DD.md. Verified: >=5 gaps identified; each has a specific "what we don't know" statement + suggested next step; narrative is readable (not just a list). (pointer: memory/scribe/timeline.py)
