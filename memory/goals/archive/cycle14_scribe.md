# Scribe - 10 goals (set 2026-11-23, cycle-14)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 14 makes the fleet's autonomous actions comprehensible: what happened, why, and what it means — synthesized into artifacts a human can review in minutes, not hours.

1. **Cycle Narrative Generator** - `python memory/scribe/cycle_narrative.py`: at cycle end, auto-generate a narrative summary (1-2 pages): theme, key achievements (top 5), notable incidents + resolutions, fleet state changes (agents added/removed, models changed), recommendations for next cycle. Emit to memory/scribe/cycles/<cycle>-narrative.md. Verified: generated from actual cycle data (goal files, incident logs, decision log); contains all 5 sections; factual claims traceable to source files; <3000 words.

2. **Decision Digest Compressor** - `python memory/scribe/decision_digest.py`: compress the full decision audit log into a human-readable digest per cycle: group by agent, highlight anomalies (unusual decisions, rollbacks, escalations), flag patterns (same trigger recurring, same action failing repeatedly). Emit to memory/scribe/digests/<cycle>-decisions.md. Verified: covers 100% of decisions from the cycle; anomalies section lists >=1 flagged item if any exist; patterns section identifies recurring triggers; <2000 words.

3. **Runbook Auto-Update** - `python memory/scribe/runbook_update.py`: when a new remediation procedure is executed successfully (from decision log), auto-update the relevant runbook section: add the verified steps, update last-verified timestamp, note any deviations from previous procedure. Emit diff of changes. Verified: 2 new procedures trigger runbook updates; updated sections contain exact steps from execution log; timestamp reflects actual execution date; no manual editing needed.

4. **Cross-Agent Handoff Summarizer** - `python memory/scribe/handoff_summary.py`: when work is handed off between agents (detected from handoff files), generate a 3-line summary: what was done, what's pending, what the receiver should know (context, gotchas, dependencies). Prepend to the handoff file. Verified: 3 handoffs summarized; each summary is exactly 3 lines; receiver can understand context without reading full history; summaries are accurate (spot-check against source).

5. **Fleet Knowledge Synthesis Report** - `python memory/scribe/kb_synthesis.py`: weekly synthesis of KB changes: what new knowledge was added, what contradictions were found/resolved, what gaps remain (topics with <2 sources), top-5 most-cited facts this week. Emit to memory/scribe/kb-weekly/<date>.md. Verified: report covers 7-day window; all sections populated from actual KB data; gap list is actionable (names specific missing topics); <1500 words.

6. **Incident Post-Mortem Auto-Filler** - `python memory/scribe/postmortem.py`: auto-fill post-mortem template from incident data: timeline (from event log), impact (affected agents/goals), root cause hypothesis (from probe correlation), actions taken (from decision log), prevention measures (suggested based on pattern match against past incidents). Emit to memory/ops/postmortems/. Verified: 2 incidents auto-filled; all template sections populated; root cause hypothesis references specific data points; prevention suggestions are concrete and actionable.

7. **Goal Progress Narrative** - `python memory/scribe/goal_narrative.py`: generate a running narrative of goal progress per cycle (updated each day): milestones hit, unexpected detours (goals that changed scope), current trajectory vs plan (on-track/at-risk/behind), predicted completion date for remaining goals. Emit to memory/scribe/progress/<cycle>-day<N>.md. Verified: updated daily during cycle; trajectory assessment matches actual data; at-risk goals are named with specific reason; <1000 words per update.

8. **Agent Performance Brief** - `python memory/scribe/agent_brief.py`: per-agent brief at cycle end: goals completed (with evidence links), assists given/received (count + summary), notable contributions (things that unblocked others), areas for improvement (slip patterns, repeated blockers). Emit to memory/scribe/briefs/<cycle>-<agent>.md. Verified: one brief per agent (7 total); all sections populated from actual data; improvement suggestions are specific and constructive; <800 words each.

9. **Fleet Change Log Synthesizer** - `python memory/scribe/change_log.py`: compress raw change logs (file changes, model swaps, config updates, agent onboarding) into a chronological narrative with causal links: "X happened, which caused Y, which required Z". Group by day; highlight days with >5 changes. Emit to memory/scribe/changelog/<date>.md. Verified: covers 7-day window; causal links are accurate (verified against timestamps); high-change days are flagged; <2000 words for week.

10. **Next-Cycle Recommendation Engine** - `python memory/scribe/cycle_recommendations.py`: based on cycle data (goal completion rates, slip patterns, incident frequency, resource utilization), generate 3-5 concrete recommendations for next cycle's focus area and goal selection. Each recommendation cites the data that motivated it. Emit to memory/scribe/recommendations/<cycle>.md. Verified: 3-5 recommendations generated; each cites specific metrics from the completed cycle; recommendations are actionable (not vague); <1000 words total.
