Verified: >=5 handoffs scored; a deliberately vague test handoff scores <50; a specific one with all fields filled scores >80; output is valid JSON. (verified: 2026-11-20 - handoff_quality.py built + selftest PASS: 6 real handoffs scored (68-92), vague fixture=20(<50), specific fixture=92(>80), valid JSON; artifact memory/scribe/handoff_quality.json)

Verified: after modifying a source file, the corresponding card is flagged; unmodified cards are not flagged; run on real data produces valid output with no false positives.
