# Researcher - 10 goals (set 2026-11-23, cycle-11)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 11 closes the autonomy loop: measure whether autonomous actions actually close their loops, quantify how evidence-supported each cockpit decision is, hold the fleet's own predictions accountable, catch stalls/risks early, and synthesize it all into ONE "fleet trust" signal the Cockpit displays beside the health score. (Cycle-10 built the *knowledge layer*; cycle-11 turns it into closed-loop decision quality.)

1. **Autonomy Loop-Closure Rate** - `python memory/researcher/loop_closure_rate.py`: parse every autonomous action in decision-log.jsonl + goal_ledger_current.json; classify each as CLOSED (detected -> acted -> verified) vs DANGLING (acted, never verified) vs REVERTED (undone by a later action). Emit per-cycle closure rate % + trend to memory/researcher/loop-closure-<cycle>.md. Verified: every logged autonomous action lands in exactly one of the 3 states; closure rate is a number in [0,1] with >=20 actions sampled; trend shows up/down/flat vs prior cycle; deterministic (same input -> same output).

2. **Decision Confidence Estimator** - `python memory/researcher/decision_confidence.py`: for each decision in decision-log.jsonl, score how well-supported it was by evidence available at decision time (count + quality of cited evidence leaves + data points) on 0-100; emit per-decision confidence + fleet-wide mean. Verified: a decision citing 3+ verified evidence leaves scores >=70; one with no citations scores <40; score monotonic in evidence count+quality; deterministic.

3. **Evidence-to-Decision Traceability** - `python memory/researcher/evidence_trace.py`: for each cockpit decision, build the provenance chain decision -> cited evidence leaves -> raw data points and verify every link resolves to an existing file/line. Output JSON (decision_id -> [{file,line,claim}]) + a broken-link report. Verified: >=95% of links resolve to real files; any dangling reference is flagged with exact decision + missing target; output valid JSON; a non-existent file is never marked resolved (negative test).

4. **Prediction Calibration Tracker** - `python memory/researcher/calibration_tracker.py`: read forecast-latest.md / next10.json predictions + their later actuals from goal_ledger_current.json; compute Brier score + reliability curve per prediction type; flag drift when recent accuracy diverges >20% from rolling baseline. Output memory/researcher/calibration-report-<cycle>.md. Verified: Brier score in [0,1]; >=15 predictions scored; a deliberately-miscalibrated synthetic set scores worse than an accurate one (negative test); deterministic.

5. **Cockpit Decision-Feed Schema** - `memory/researcher/cockpit-decision-feed.md`: spec the JSON contract the Fleet Cockpit consumes for decision-quality signals - fields {decision_id, confidence, loop_state, evidence_count, calibration_bucket} + timestamping + the /api endpoint shape Builder should expose. Verified: schema lists every field with type + example; a sample document validates against it; >=3 worked examples (closed/high-conf, dangling/low-conf, miscalibrated); states endpoint path + method so Builder wires without re-deriving.

6. **Autonomous Action Replay** - `python memory/researcher/action_replay.py`: given a past autonomous action that failed or was reverted, reconstruct the exact evidence/data state available at decision time and report whether an alternative choice was supportable (counterfactual). Output per-action record to memory/researcher/action-replays/. Verified: on 3 real reverted/failed actions each replay names the data available + >=1 alternative considered; runtime <10s/action; deterministic; never invents evidence that did not exist at decision time.

7. **Autonomy Risk Register** - `python memory/researcher/autonomy_risk_register.py`: scan OPS-NOTE/NEEDS-HUMAN entries in memory/ops/blockers.md + incident records for *autonomy-specific* failure modes (stale-goal dispatch, mirror clobber loop, egress wall, stale-verify claims); score each by frequency x blast-radius; emit a live register to memory/researcher/autonomy-risk-register.json. Verified: >=4 distinct autonomy risk modes captured; each has count + last-seen date + one-line mitigation status; JSON valid; a newly-planted risk mode is picked up on re-run (negative test).

8. **Loop-Stall Predictor** - `python memory/researcher/loop_stall_predictor.py`: from an agent's recent turn history (repeated no-file-change turns, same blocker re-probed, stale goal set dispatched), predict stall likelihood 0-1 and emit a warning before budget is wasted. Output per-agent risk to memory/researcher/stall-alerts.jsonl. Verified: on a synthetic 6-turn no-progress sequence the probability rises monotonically toward 1; on a productive sequence stays <0.3; uses only features computable from memory/ (no network); deterministic.

9. **Fleet Trust Score** - `python memory/researcher/fleet_trust_score.py`: combine loop-closure rate (#1), mean decision confidence (#2), calibration accuracy (#4) and conflict count (knowledge-conflicts.md) into ONE 0-100 "fleet trust" number + delta vs last cycle. Append one row/cycle to memory/researcher/trust-score.jsonl. Verified: score in [0,100]; each component's weight stated; a synthetic high-trust state scores > a low-trust state by >=20 points; deterministic; appends exactly one row per run (idempotent on same input).

10. **Trust-Pipeline Self-Check** - `python memory/researcher/trust_selfcheck.py`: test harness that runs #1/#2/#4/#9 against fixtures and asserts invariants (score bounds, monotonicity, determinism, JSON validity) so the cockpit data pipeline cannot silently rot. Verified: 10/10 assertions pass on clean fixtures; at least one negative fixture per component makes its corresponding assertion fail; exit code reflects pass/fail; runtime <20s.
