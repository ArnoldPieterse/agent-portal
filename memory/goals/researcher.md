# Researcher — Cycle 15 Goals (set 2026-11-24)
Round topic: **Fleet Autonomy Convergence**
Pillars: (1) Mode Controller, (2) Dispatch Correctness, (3) Idle Productivity

1. **Productivity Baseline Measurement** - `python memory/researcher/idle_productivity.py`: measure per-agent productive-pass rate over last 24h (file changes / total passes from autoloop.jsonl). Write to memory/ops/productivity-baseline.json with fields: agent, pass_count, productive_count, rate, flag (bool if <30% for 2+ days). Verified: script runs <5s; output JSON has all fields; flags correct on synthetic test data with known below-threshold agents.

2. **Goal Proposal Auto-Generator** - `python memory/researcher/goal_proposer.py`: scan decision-log.jsonl + blockers.md + hot notes for recurring patterns (>3 occurrences of same root cause keyword). Generate draft cycle proposal (markdown) with one goal per pattern, pre-filled with verification criteria. Verified: on real data, generates >=3 valid proposals; each has a testable acceptance criterion; no duplicates vs closed_topics.json (checked programmatically).

3. **Mode Duration Tracker** - `python memory/researcher/mode_duration.py`: read mode-transitions.jsonl; compute time spent in each mode over last 7 days. Write to memory/ops/mode-durations.json. Flag anomaly if IDLE >50% of total time (suggests under-utilization) or WORK <20% (suggests stuck goals). Verified: on synthetic transition data, durations sum to total elapsed; anomaly flags trigger correctly at threshold boundaries.

4. **Idle Waste Quantification** - `python memory/researcher/idle_waste.py`: from autoloop.jsonl, quantify: (a) total passes where agent received generic menu vs specific task, (b) productive rate for each type, (c) estimated wasted compute (passes x avg_duration). Write report to memory/researcher/idle-waste-report.md. Verified: on data with mixed generic/specific dispatches, report shows specific tasks have >2x productive rate; waste estimate is arithmetically correct.

5. **Convergence Velocity Metric** - `python memory/researcher/convergence_velocity.py`: for each completed cycle, compute: goals_closed / total_passes_used = velocity. Track trend across cycles 10-15. Write to memory/ops/velocity-trend.json. Flag if velocity declining >2 consecutive cycles. Verified: on historical data, computes correct per-cycle velocity; trend array has one entry per cycle; decline flag triggers on synthetic declining data.

6. **Dispatch Correctness Audit** - `python memory/researcher/dispatch_audit.py`: sample last 50 auto-loop passes from autoloop.jsonl; for each, verify: (a) agent was not dispatched for a reached goal, (b) in MAINT/IDLE mode, task was specific (not generic menu). Write pass/fail report. Verified: on post-fix data, reports 0 violations; on synthetic pre-fix data, correctly flags >=5 violations with specific pass IDs.

7. **Pattern Recurrence Detector** - `python memory/researcher/pattern_detector.py`: scan decision-log.jsonl for root-cause keywords appearing >3 times in last 7 days. Output: ranked list of patterns with count, first_seen, last_seen, affected_agents. Write to memory/ops/recurring-patterns.json. Verified: on synthetic data with 4 known patterns (one at threshold 3, one above), detector finds all 4+ correctly; ranking is by frequency descending.

8. **Mode Transition Forecast** - `python memory/researcher/mode_forecast.py`: based on current goal completion rate + historical cycle duration, predict: (a) when fleet will reach 100% (WORK->MAINTENANCE), (b) when MAINTENANCE->IDLE (6h threshold). Write prediction to memory/ops/mode-forecast.json. Verified: on synthetic data with known completion rate, predicted time is within 20% of actual; forecast file updates on each run.

9. **Productive Pass Definition** - Write memory/researcher/productive-pass-definition.md: formal definition of "productive pass" per role (e.g., Researcher: new measurement or KB entry; Builder: file created/modified with >10 lines changed; Verifier: test result written). Include edge cases (what counts as partial credit). Verified: document exists; all 8 roles have explicit definitions; definitions are mutually exclusive (a pass can't be productive for two roles simultaneously).

10. **Cycle Efficiency Report** - `python memory/researcher/cycle_efficiency.py`: at cycle close, compute: total_passes, productive_pct, goals_closed_per_agent, time_to_100pct, avg_pass_duration, wasted_pass_count. Write to memory/ops/cycle-efficiency-{N}.json. Verified: on real cycle-14 data, all fields populated; productive_pct matches manual count from autoloop.jsonl (within 5%); report generated <10s.
