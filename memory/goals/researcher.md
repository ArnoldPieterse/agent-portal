# Researcher — Goals (NEXT cycle, proposed 2026-11-23)
Round topic: **Closed-Loop Autonomy & Fleet Cockpit**
Status: PROPOSED for next cycle (Orchestrator to collect verbatim into TODO.md '## AGENT GOALS'). Prior-cycle detector/audit set is complete; this set advances the loop from DETECT -> ACT / MEASURE-VALUE / SIMULATE / GUARDRAIL. None re-issue the prior 10 or any closed topic.

1. **Self-Healing Remediation Bus** - `python memory/researcher/remediation_bus.py`: consume detector outputs (stale_claim_scan, dispatch_desync, reach_matrix, clobber-manifest) and APPLY safe, idempotent remediations — re-land a clobbered endpoint via elev.py, clear a confirmed-stale verified-marker, trigger the mtime-gated reload — each with an audit-trail entry {detector, action, before, after, rollback}. This is the layer that actually closes the loop (detection -> action) instead of only reporting. AC: given synthetic clobber + desync fixtures it applies the correct fix and logs a reversible audit line; re-running is idempotent (no double-apply).

2. **Instrument ROI / Effort-Attribution Model** - `python memory/researcher/instrument_roi.py`: using loop_telemetry.jsonl + closure data, attribute changes in empty-pass rate and blocker-resolution time to the specific instrument that fired (did stale_claim_scan reduce later re-work? did reach_matrix cut manual diagnosis time?); emit per-instrument ROI so the fleet decides what to keep building. AC: produces a signed effect estimate for >=3 instruments from real telemetry; flags any instrument with net-negative or zero attribution.

3. **Goal-Dependency & Critical-Path Analyzer** - `python memory/researcher/goal_critical_path.py`: parse cross-lane handoffs (memory/handoffs/) + goal text to build a dependency graph across agents' open goals; compute the critical path and flag any goal that blocks 2+ others so dispatch unblocks it first. Distinct from forecast/cadence (those predict timing; this maps structural blocking). AC: emits a ranked unblock-priority list from live handoff/goal data with >=1 real blocker identified.

4. **Calibration-to-Dispatch Feedback** - `python memory/researcher/calib_dispatch.py`: close the prediction loop by FEEDING calibration error back into dispatch — seats/goals that consistently slip get their next-cycle weight reduced; emit a proposed re-weighting + rationale. (The closed calibration_tracker only MEASURED error; this CHANGES dispatch behavior.) AC: from >=2 cycles of predicted-vs-actual it emits at least one concrete re-weighting with the underlying slip evidence.

5. **Blocker -> Catch -> Fix -> Verify Runbook** - `memory/researcher/blocker-loop-runbook.md`: auto-maintained runbook linking each OPS-NOTE blocker to (a) the detector that catches it, (b) the exact remediation step, (c) the verify command, and (d) rolling success rate; self-updates as new blockers are recorded. Broader than the closed Blocker Triage (classify-only) and clobber-manifest (clobber-only). AC: >=5 real historical blockers each carry all four fields + a measured success rate.

6. **Research-Instrument Health Feed** - `python memory/researcher/instrument_health.py`: emit a cockpit data feed reporting the health of my own instruments — last-run time, coverage, current FP rate, last alert, staleness — so the fleet can see which detectors are silent/broken (meta-observability). AC: one JSON record per instrument with last_run + status; flags any instrument not run in >2 cycles. (pointer: memory/researcher/scribe-memory-health-relanded-2026-11-17.md)

7. **Whole-Cycle State Snapshot & Diff Store** - `python memory/researcher/cycle_snapshot.py`: at each cycle close, persist a compact hash of goal files + ledger + closed_topics; on the next transition emit a diff (what was added/removed/archived) and flag any lossy carry-over. (Closed autonomous_action_replay covered a single action; this is whole-cycle state for replay/what-if + it validates the auto-transition auditor.) AC: two consecutive cycles produce a valid diff; a seeded lost-file case is flagged.

8. **Cockpit Data Golden-Fixture Regression** - `python memory/researcher/cockpit_golden.py`: Playwright end-to-end gate that renders each cockpit panel and diffs its DATA (not just page-load) against golden fixtures, so any data-completeness regression is caught in-loop. Distinct from Builder's UI Module Test Suite (module-load only). AC: runs green on current state; a seeded clobbered endpoint makes exactly the affected panel fail.

9. **Closed-Loop Failure-Mutation Library** - `python memory/researcher/failure_mutation.py`: versioned regression library encoding each documented failure mode (clobber, desync, stale verified-marker, phantom count) as a reproducible fixture + mutation that must be CAUGHT by the right detector; tracks per-detector catch-rate. Extends beyond the one-shot Trust-Pipeline Self-Check into a maintained library with NEW classes + mutation coverage. AC: >=6 fixtures each caught by the intended detector; an injected mutation that no detector catches is reported as a coverage gap.

10. **Autonomy Guardrails & Blast-Radius Registry** - `python memory/researcher/blast_radius.py`: before any self-healing action (goal #1) executes, compute its blast radius (files/hosts/endpoints affected) and gate on a risk class {safe|review|halt}; the safety layer that lets #1 run unattended. AC: for each remediation type it returns an explicit blast-radius set + risk class; a seeded high-blast action is gated to review/halt, not auto-applied.
