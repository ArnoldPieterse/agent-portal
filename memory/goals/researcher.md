# Researcher - 10 goals (set 2026-11-23, cycle-10)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 10: the research lane provides the knowledge layer that makes autonomous decisions trustworthy - evidence quality, pattern recognition, and knowledge freshness.

1. **Fleet State Narrative Summarizer** - `python memory/researcher/fleet_summary.py`: generate a 3-5 sentence natural-language summary of fleet state from cockpit data (health score, active goals, predicted risks, recent incidents). Write to memory/ops/fleet-summary-YYYY-MM-DD.md each cycle. Verified: summary accurately reflects cockpit data (no hallucinated metrics); <=5 sentences; includes at least one actionable insight; generated in <10s.

2. **Evidence Quality Auto-Scorer** - `python memory/researcher/evidence_scorer.py`: score all new evidence leaves (memory/*/evidence-*.md) on: completeness (all required fields), specificity (concrete values not vague claims), reproducibility (command to re-run provided). Score 0-10 per criterion. Verified: a well-formed evidence leaf scores >=8/10 overall; a vague one scores <5; scoring is deterministic (same input -> same score). (pointer: memory/researcher/evidence-quality-2026-11-20.md)

3. **Cross-Agent Pattern Detector** - `python memory/researcher/cross_patterns.py`: parse all agents' goal completions + incident records from the last 3 cycles; identify patterns no single agent would see (e.g., "Builder goals slip when Verifier is on a different host"). Output: memory/researcher/cross-patterns-cycle10.md with >=3 patterns + confidence. Verified: each pattern cites >=2 data points; at least one pattern is non-obvious (not stated in any single agent's notes); patterns are actionable.

4. **Knowledge Decay Model** - `python memory/researcher/knowledge_decay.py`: build a mathematical model for how quickly different knowledge types become stale (API docs: fast, architecture decisions: slow, bug fixes: medium). Calibrate against actual correction history in memory/. Output: decay half-life per type + confidence. Verified: model predicts staleness within 20% of actual correction timing on historical data; covers >=4 knowledge types; output includes formula + parameters.

5. **Research Gap Detector** - `python memory/researcher/gap_detector.py`: scan all memory/ leaves to identify topics where the fleet has no depth (fewer than 2 substantive entries). Cross-reference with open goals to see if gaps are being addressed. Output: memory/researcher/knowledge-gaps.md ranked by impact. Verified: identifies >=3 genuine gaps; each gap has a suggested goal or action; no false positives (topics with adequate coverage not flagged). (pointer: memory/researcher/MEMORY.md)

6. **Source Reliability Ranking** - `python memory/researcher/source_ranking.py`: maintain a dynamic ranking of information sources (hosts, APIs, documentation pages) by accuracy over time. When a source's data is contradicted, lower its rank. Output: memory/researcher/source-ranks.json updated each cycle. Verified: ranking updates when contradictions are found; top-ranked source has >=90% historical accuracy; at least 5 sources ranked; JSON valid. (pointer: memory/researcher/evidence-source-scorer-2026-11-18.md)

7. **Fleet Memory Compression** - `python memory/researcher/memory_compress.py`: identify redundant/overlapping knowledge across agents (same fact stated in 3+ places) and propose consolidation into a single canonical location with pointers. Output: compression report + proposed changes. Verified: identifies >=3 genuine redundancies; proposed consolidation preserves all information; no lossy compression (every fact retained in exactly one place).

8. **Anomaly Narrative Generator** - `python memory/researcher/anomaly_narrative.py`: when an anomaly is detected in fleet metrics (health score drop, response time spike, VRAM breach), auto-generate a 2-3 sentence explanation of what likely happened + recommended action. Write to decision-log context field. Verified: on 3 historical anomalies, narratives are plausible and cite the correct metric; each includes a recommended action; generation <5s per anomaly.

9. **Historical Precedent Matcher** - `python memory/researcher/precedent_match.py`: given a current incident description, find the most similar past incident from records + its resolution. Use keyword overlap + severity matching. Output: top-3 matches with similarity scores. Verified: on 5 test incidents (from actual history), correct match is in top-3; similarity scores are monotonic (closer = higher); runtime <10s per query.

10. **Knowledge Conflict Detector** - `python memory/researcher/conflict_detector.py`: scan memory/ for contradictory statements (e.g., "host X has 24GB VRAM" in one file, "16GB" in another). Flag with both sources + suggested resolution. Output: conflict report to memory/researcher/knowledge-conflicts.md. Verified: a planted contradiction is detected; false positive rate <10% on clean data; each conflict cites both exact locations; resolution suggestion provided.
