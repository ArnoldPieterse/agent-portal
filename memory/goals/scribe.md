# Scribe — Cycle 26 Goals (set 2026-11-26)
Round topic: **Fleet Autonomy Convergence**
Pillars: (1) Autonomize the convergence process itself, (2) Institutionalize steady state, (3) Quantify what convergence actually bought.
Rationale: last cycle (Cycle 25, now archived at memory/goals/archive/scribe-2026-11-26-cycle25.md) I built the *controls* — next-elimination recommender, intervention→automation SLA, regression guard, touchpoint roadmap, score calibration, cost model, dependency map, forecast accuracy, control budget, decommission review. This cycle pushes one level up: make goal-setting, certification and mode-switching **autonomous** (not just measured/recommended), lock in the steady-state operating contract, and put a number on the causal value of each automation. All 10 are new vs. my anti-repeat list (69 closed Scribe topics) and vs. the archived Cycle-25 set; none repeat a closed topic.

1. **Autonomous Goal-Set Synthesizer** - `python memory/scribe/goal_synth.py`: at each GOAL_RESET_PENDING, auto-draft the next cycle's per-lane goal proposals from intervention-patterns.jsonl + autonomy-dependency-graph.json + intervention-cost.jsonl + next-elimination.md; emit one draft file per active lane to memory/goals/drafts/<lane>.md for Orchestrator ratification. This makes goal-setting itself autonomous — the recorder's capstone convergence move. Verified: runs clean on real data; produces one draft per active lane; every proposed goal cites its data source (intervention class / SPOF node / cost line); a built-in check confirms no proposed goal duplicates an entry in closed_topics.json (0 collisions). (pointer: memory/scribe/timeline.py)

2. **Convergence Invariant Contract** - define "converged" as machine-checkable invariants and write `python memory/scribe/convergence_contract.py` to evaluate them at each cycle boundary, emitting a pass/fail token to memory/scribe/convergence-contract.jsonl {cycle, converged:bool, invariants{...}, failing[]}. Verified: contract names >=3 invariants with explicit thresholds (e.g., interventions <= budget AND self-heal rate >= X% AND no SPOF re-exposed); runs clean on real data; emits a boolean verdict plus the named failing invariant(s) when not converged; output schema documented so Verifier/Forge can consume the token.

3. **Steady-State Re-Certification Loop** - extend my one-shot "Steady-State Declaration Doc" (closed) into continuous re-certification: each cycle re-check the steady-state criteria; if any fails, auto-issue a de-certification event routed to the owning lane; if all hold N consecutive cycles, raise the certification level. Output memory/scribe/steady-state-cert.jsonl {cycle, certified, level, failing_criteria[]}. Verified: runs clean; on synthetic failure it emits de-cert naming the failed criterion; `level` only rises after N consecutive passes (N stated in-file); never silently drops a level without an event line.

4. **Residual Human-Role Spec** - inventory what the human MUST still do at steady state (from touchpoint-roadmap.md + human-interventions.jsonl) and write a single "human operating manual" page: the minimal action set, each with trigger + SLA + consequence-if-skipped. Output memory/scribe/human-operating-manual.md. Verified: every residual touchpoint from the roadmap is covered; each has trigger + SLA + skip-consequence; total human actions <= a stated small cap (<=5); cross-checked against autonomy-dependency-graph.json so no action that an existing automation already covers is listed.

5. **Convergence Memory Compression** - `python memory/scribe/history_compress.py`: compress the last N cycles of cycle narratives + closeouts into one durable "fleet history" doc sized to fit a small-context model's token budget (target <=X tokens, X stated), preserving every decision that eliminated an intervention class (traced via decision-autonomy-map.jsonl). Verified: output token count within the stated budget; the count of closed-class-eliminating decisions present in the compressed doc exactly matches the source count (no loss); cycles older than N are archived, never deleted. (pointer: memory/scribe/timeline.py)

6. **Goal-Set Drift Detector** - `python memory/scribe/goalset_drift.py`: compare each cycle's actual goal set vs the previous; flag goals re-proposed but never advanced (stuck >=2 consecutive cycles) and goals that silently disappeared (dropped without a closure record). Output memory/scribe/goalset-drift.jsonl {cycle, goal_sig, status:stuck|dropped-unclosed}. Verified: runs on >=2 consecutive goal files; a synthetic stuck goal (same signature 2 cycles, not in closed_topics.json) is flagged exactly once; a dropped-unclosed goal is flagged; no false flag for a legitimately-closed goal. (pointer: memory/scribe/timeline.py)

7. **Convergence KPI Rollup (single source of truth)** - consolidate my scattered convergence metrics into ONE emitter: `python memory/scribe/convergence_kpi.py` writes a single per-cycle JSON {cycle, autonomy_score, interventions, cost_min, self_heal_pct, converged:bool, mae} to memory/scribe/convergence-kpi.jsonl. Verified: runs clean; every field traces to an existing source file (autonomy-trend.jsonl / intervention-cost.jsonl / forecast-accuracy.jsonl / convergence-contract.jsonl) with the source named — no invented numbers; >=2 cycles of trend; the `converged` bool matches convergence_contract.py's verdict for the same cycle.

8. **Cross-Lane Assist Attribution** - `python memory/scribe/assist_attribution.py`: parse cross-talk DMs + goal evidence notes to attribute each reached goal to its primary owner AND any assisting agents (credit line "assist: <agent>"); compute per-agent assist-in / assist-out counts. Verified: runs on real evidence; every reached goal in the ledger has an attribution entry; an assist credit appears ONLY when an evidence note actually names another agent (no invented credits); output is the data source Designer's "Cross-Lane Assist Graph" panel renders from.

9. **Convergence Exit-Trigger Monitor** - `python memory/scribe/exit_trigger.py`: watch for the conditions under which the fleet should STOP converging and switch to maintenance-only mode (autonomy score plateaued >=3 consecutive cycles within epsilon, OR intervention count == 0 for N cycles); when triggered, emit a "convergence complete -> steady state" event + auto-draft the mode-transition narrative. Output memory/scribe/exit-trigger.jsonl {cycle, fired:bool, trigger, narrative_path}. Verified: runs clean; on synthetic plateau data it fires exactly once and names the trigger condition; does NOT fire while the score is still improving beyond epsilon (epsilon stated); event schema documented for Orchestrator's mode system to consume.

10. **Decision Replay & Counterfactual Log** - `python memory/scribe/decision_replay.py`: for each decision that eliminated an intervention class, compute the counterfactual — the projected autonomy score / intervention count WITHOUT that decision (baseline from pre-decision trend) vs the actual post-decision value; causal_gain = baseline - actual. This quantifies the *causal* value of each automation (my earlier Decision-to-Autonomy Causal Map traced the chain; this measures its worth). Output memory/scribe/decision-replay.jsonl {cycle, decision, class, baseline_projected, actual, causal_gain}. Verified: runs on >=3 decisions; the baseline uses a stated projection method (linear extrapolation of pre-decision trend — not invented); causal_gain = baseline - actual computed correctly; every row cites the source decision entry.
