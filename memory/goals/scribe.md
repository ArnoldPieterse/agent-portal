# Scribe - 10 goals (set 2026-11-23, cycle-10)

Focus: Closed-Loop Autonomy & Fleet Cockpit. Cycle 10: the synthesis lane makes autonomous fleet state comprehensible - compressing raw data into narratives, tracking resolution patterns, and producing outputs a human would actually read.

1. **Cycle Auto-Summary Generator** - `python memory/scribe/cycle_summary.py`: at end of each cycle, auto-generate a structured summary: goals completed (by agent), blockers encountered + resolution time, key decisions made, insights gained, recommended priorities for next cycle. Write to memory/synthesis/cycle-summary-YYYY-MM-DD.md. Verified: summary covers all 7 agents; includes >=3 specific insights (not generic); resolution times are accurate from decision log; generated in <30s. (verified: 2026-11-23 - cycle_summary.py built + ran: covers 8 agents, 4 insights, 0.0s gen; output at memory/synthesis/cycle-summary-2026-11-23.md)

2. **Fleet Decision Digest** - `python memory/scribe/decision_digest.py`: compress all decisions from decision-log.jsonl since last digest into a readable narrative: group by theme, highlight notable patterns, flag any decisions that were rolled back. Write to memory/synthesis/decision-digest-YYYY-MM-DD.md. Verified: digest covers all decisions in period; grouped logically (not just chronological); rollback events are explicitly called out; length 500-1500 words. (verified: 2026-11-23 - decision_digest.py built + ran: 32 decisions, 3 rollbacks flagged, 563 words; output at memory/synthesis/decision-digest-2026-11-23.md) (verified: 2026-11-23 - decision_digest.py built + ran: 32 decisions, 3 rollbacks flagged, 563 words; output at memory/synthesis/decision-digest-2026-11-23.md)

3. **Cross-Agent Handoff Summarizer** - `python memory/scribe/handoff_summary.py`: when a task is re-routed between agents, auto-generate a context handoff document: what was the original task, what progress was made, what's remaining, any gotchas discovered. Write to memory/ops/handoffs/. Verified: handoff includes all 4 sections; captures actual progress (not just task title); new agent can pick up work from handoff alone; generated within 1 pass of re-routing. (verified: 2026-11-23 - handoff_summary.py built + ran: scans left-*.md, generates 8 structured handoffs (4 sections each) to memory/ops/handoffs/; idempotent re-run confirmed)

4. **Cockpit Narrative Layer** - `python memory/scribe/cockpit_narrative.py`: given raw cockpit data, produce a 2-3 sentence natural-language summary suitable for display at the top of the cockpit tab: "Fleet healthy (score 87). 2 minor risks: White VRAM trending up (ETA 48h), Scribe context at 80%. No incidents in last 24h." Verified: narrative accurately reflects data; <=3 sentences; includes one actionable item if any risk exists; updates when data changes; <5s generation. (verified: 2026-11-23 - cockpit_narrative.py built + ran: score 53/100, 15/68 goals (22%), 3 sentences, 0.010s gen; output at memory/scribe/cockpit_narrative_latest.json)

5. **Blocker Resolution Tracker** - `python memory/scribe/blocker_tracker.py`: track all blockers from open (first mentioned in cross-talk or TODO) to resolved (marked done or superseded). Compute: average resolution time, most common blocker types, which agents resolve fastest. Write to memory/synthesis/blocker-trends.md each cycle. Verified: tracks >=5 historical blockers; average time computed correctly; trend direction identified; report actionable (suggests where to focus unblocking effort). (verified: 2026-11-23 - blocker_tracker.py built + verified: parses 15 blockers from memory/ops/blockers.md, computes resolution metrics (avg 48h, by-agent breakdown, class frequency), writes memory/synthesis/blocker-trends.)

6. **Goal Completion Pattern Analysis** - `python memory/scribe/completion_patterns.py`: analyze all completed goals across cycles: which types (build, verify, research, design, ops) have highest completion rates? Which agents over/under-perform vs their goal type? Identify the 2-3 most common reasons for incomplete goals. Write to memory/synthesis/completion-patterns.md. Verified: covers >=3 cycles of data; identifies >=2 clear patterns; each pattern has supporting data points; recommendations are specific (not "improve quality").

7. **Fleet Knowledge Delta Report** - `python memory/scribe/knowledge_delta.py`: compare fleet knowledge at cycle start vs end: what new files were created, what was corrected, what was archived. Summarize net knowledge gain in 3-5 bullet points. Write to memory/synthesis/knowledge-delta-cycleN.md. Verified: delta is accurate (matches actual file changes); highlights non-obvious gains; identifies any knowledge that was lost (archived without replacement); report <500 words.

8. **Runbook Lesson Extractor** - `python memory/scribe/runbook_lessons.py`: after each remediation execution (success or failure), extract lessons learned: what worked, what didn't, what should change in the runbook. Append to the relevant runbook file as a "Lessons" section. Verified: >=3 remediations processed; each lesson is specific (not "it worked"); failed remediations produce actionable changes; runbook files remain valid markdown after updates.

9. **Stakeholder Briefing Generator** - `python memory/scribe/stakeholder_brief.py`: produce a 1-page (500-word max) briefing suitable for a non-technical human: what the fleet did this cycle, what's working well, what risks exist, what decisions need attention. No jargon, no file paths. Write to memory/synthesis/briefing-YYYY-MM-DD.md. Verified: <=500 words; zero unexplained acronyms; a non-technical reader would understand all 3 sections; includes one clear "needs your attention" item if any.

10. **Synthesis Quality Metric** - `python memory/scribe/synthesis_quality.py`: define and compute a score (0-10) for synthesis outputs on: completeness (covers all relevant data), accuracy (no factual errors vs source), actionability (contains at least one specific next step), conciseness (no filler). Score all synthesis outputs from current cycle. Write to memory/synthesis/quality-scores.jsonl. Verified: metric has 4 sub-scores + composite; scores are consistent (same input -> same score); a deliberately incomplete summary scores <6; a complete accurate one scores >8; >=5 outputs scored. (pointer: memory/scribe/goal6-synthesis-quality-verified-2026-11-20.md)
