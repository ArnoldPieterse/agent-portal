# Scribe — Cycle 15 Goals (set 2026-11-24)
Round topic: **Fleet Autonomy Convergence**
Pillars: (1) Mode Controller, (2) Dispatch Correctness, (3) Idle Productivity

1. **Mode Transition Narrative** - `python memory/scribe/mode_narrative.py`: when fleet mode changes, auto-generate a 3-sentence narrative: what changed, why (trigger), what it means for agents. Write to memory/ops/mode-narratives.jsonl. Example: "Fleet entered MAINTENANCE at 14:32 UTC after all 80 goals reached 100%. Trigger: goal_pct=100, elapsed_since_last_activity=2h. Agents will now receive role-specific maintenance tasks instead of goal dispatch." Verified: on 3 simulated transitions, narratives are grammatically correct, cite actual trigger values, and appear in JSONL within one pass. (pointer: memory/scribe/timeline.py)

2. **Cycle Close-Out Report** - `python memory/scribe/cycle_closeout.py`: at cycle close, generate structured report: goals completed (by agent, with evidence refs), blockers encountered + resolution time, key decisions made, velocity vs prior cycle, recommendations for next cycle. Write to memory/synthesis/cycle-{N}-closeout.md. Verified: on cycle-14 data, report has all 5 sections; each goal cited has matching evidence path; file <4KB. (pointer: memory/scribe/cycle_closeout.py)

3. **Idle Pass Daily Digest** - `python memory/scribe/idle_digest.py`: at end of each day, summarize idle passes: total idle passes, tasks assigned (by agent), productive rate, top 3 waste sources (most frequent non-productive task types). Write to memory/ops/idle-digest-{date}.md. Verified: on a day with 20 idle passes, digest lists all 20 with tasks; productive rate matches autoloop.jsonl count; top-3 waste sources are correctly ranked by frequency. (pointer: memory/scribe/timeline.py)

4. **Productivity Story (Weekly)** - `python memory/scribe/productivity_story.py`: weekly narrative (5-8 sentences) on fleet productivity evolution: what changed, which agents improved/declined, what interventions helped. Write to memory/synthesis/productivity-week-{ISO}.md. Verified: on 7 days of synthetic data with known trend, story correctly identifies direction; cites specific agents + metrics; no hallucinated data (all numbers traceable to baseline files). (pointer: memory/scribe/timeline.py)

5. **Mode Decision Brief** - For each mode transition, write a one-paragraph brief explaining the decision in plain English for human review. Include: current state, what triggered change, expected duration in new mode, what happens next. Append to memory/ops/mode-briefs.md (newest first). Verified: after 3 transitions, file has 3 briefs; each is 4-6 sentences; all factual claims match fleet-mode.json + goal state at that time.

6. **Cross-Agent Handoff Summary** - When goals re-route between seats (due to unavailability), generate a context summary for the receiving agent: what the goal was, prior progress, key files involved, suggested first step. Write to memory/handoffs/{date}-{from}-{to}.md. Verified: on simulated re-route of 2 goals, handoff notes exist; each cites correct source agent + goal text; receiving agent's dispatch includes the handoff file path.

7. **Cycle Efficiency Digest** - Per cycle: one-paragraph summary of efficiency metrics (passes used, productive %, goals/cycle, time-to-100%, trend arrow vs prior 3 cycles). Write to memory/ops/efficiency-digest-{N}.md. Verified: on real data, numbers match cycle-efficiency.json; trend arrow is correct (up/down/stable); paragraph is <80 words.

8. **Anomaly Narrative Generator** - `python memory/scribe/anomaly_narrative.py`: when any fleet metric deviates >2σ from 30-day baseline, generate plain-English explanation: what deviated, by how much, likely cause (from decision-log context), recommended action. Write to memory/ops/anomaly-{timestamp}.md. Verified: on synthetic data with 1 known anomaly, narrative identifies correct metric + direction; cause is grounded in actual log entries (not fabricated); recommendation is actionable.

9. **Fleet State Snapshot (Daily)** - `python memory/scribe/daily_snapshot.py`: generate a 10-line human-readable snapshot of fleet state: mode, open goals count, top 3 active agents, productivity rate, pass budget remaining, last incident, next expected transition, blocked items, today's key decisions, tomorrow's focus. Write to memory/ops/snapshot-{date}.md. Verified: all 10 lines present; each line <80 chars; data matches actual fleet state at generation time; file generated daily (check mtime).

10. **Convergence Velocity Briefing** - Per cycle: 3-sentence briefing on convergence speed: "Cycle N reached 100% in X hours using Y passes (Z productive%). Compared to prior cycle: [faster/slower] by W%. Primary factor: [what drove the difference]." Write to memory/ops/velocity-brief-{N}.md. Verified: numbers match actual cycle data; comparison is arithmetically correct; primary factor is grounded in decision-log (not speculative).
