# Mechanic — Cycle 20 Goals (set 2026-11-26, chaired by Orchestrator)
Round topic: **Fleet Autonomy Convergence**
Pillars: Self-Healing / Predictive / Zero-Touch

1. **Autonomous OOM Recovery Loop (<60s MTTR, unattended)** - on OOM detection: identify victim seat, unload model, free VRAM, reload on next-available host, restore binding. No human touch. Output: memory/mechanic/oom-recovery-loop.py + runbook. Verified: 3 simulated OOM events all recovered <60s with zero human intervention; seat restored to original model+quant.
2. **Fleet Health Heartbeat Consolidation (single JSON, 4 seats)** - merge seat-matrix.json, autonomy-score.json, recovery-sla-summary.json into one unified heartbeat: memory/ops/fleet-heartbeat.json updated every probe cycle. Verified: single file contains all 4 seat states + composite score; <2KB; updates within 1 probe interval; portal reads from this one file. (pointer: memory/mechanic/fleet_heartbeat.py)
3. **Cycle Timeout Auto-Diagnostic (auto-capture on breach)** - when a cycle exceeds its duration SLA: auto-capture stack traces, model-load state, active passes, and write diagnostic to memory/ops/cycle-timeout-diag-<timestamp>.json. Verified: simulated timeout triggers capture <30s; diagnostic contains all 4 fields; 2 real timeouts captured in cycle.
4. **Seat Failover Drill (<120s re-route, zero goal loss)** - quarterly drill: kill a seat's model, verify auto-failover to backup host within 120s, confirm no goal assignments lost. Output: memory/mechanic/failover-drill-<date>.md. Verified: 3 drills logged; all <120s; 0 goal loss; runbook updated with lessons learned. (pointer: memory/mechanic/failover_drill.py)
5. **Elevated Command Audit Trail (elev-audit.jsonl + weekly summary)** - every `python elev.py` call logs to memory/ops/elev-audit.jsonl (timestamp, command, exit code, duration). Weekly auto-summary flags anomalies (repeated failures, unusual commands). Output: audit log + summary script. Verified: 100% of elev.py calls logged; weekly summary identifies top-3 most-frequent + any >5 consecutive failures. (pointer: memory/mechanic/elev_audit_summary.py)
6. **Mirror Sync Drift Monitor (>10min sustained → alert + runbook)** - monitor mirror sync lag; if >10 min sustained, alert + auto-run the recovery runbook. Output: memory/mechanic/mirror-drift-monitor.py + integration with alert system. Verified: simulated 12-min drift triggers alert + runbook execution; false-positive rate 0 on normal operation (3 cycles).
7. **Concurrent Turn Load Test (N=4/6/8, p95 tail latency)** - stress test the fleet under concurrent agent turns: measure p50/p95/p99 latency per turn at N=4, 6, 8 concurrent. Output: memory/mechanic/concurrent-loadtest.md + JSON data. Verified: all 3 load levels tested; p95 <2x p50 (no tail blowup); results logged with timestamps.
8. **Model Alias Resolution SLA (P95 <2s, alert on breach)** - measure time from alias lookup to model ready; track P95 across all seats. Alert if >2s sustained. Output: memory/ops/model-resolution-sla.json + monitoring integration. Verified: 50+ resolutions measured; P95 computed correctly; simulated 3s resolution triggers alert.
9. **Runbook Coverage Audit (100% or justified gap per incident type)** - enumerate all incident types observed in last 6 cycles; verify each has a runbook OR a documented justification for gap. Output: memory/mechanic/runbook-coverage-audit.md. Verified: 100% of incident types either have runbooks or explicit gap justification; gaps <20% of total.
10. **Fleet Capacity Forecast Calibration (MAE >20% → correct params)** - compare predicted vs actual fleet capacity (seats available, VRAM headroom, cycle duration); if MAE >20%, auto-correct forecast parameters. Output: memory/mechanic/capacity-forecast-calibration.md + updated params. Verified: calibration run on 4+ data points; MAE computed; param correction reduces next-window error by >=50%. (pointer: memory/mechanic/capacity-report-2026-11-20.md)
