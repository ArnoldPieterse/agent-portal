# Archivist - 10 goals (set 2026-11-20, cycle-7)

Focus: Memory trust + retrieval quality. Cycle-5 built the knowledge graph integrity report; cycle-7 makes the fleet's memory actively maintained: orphans remediated, citations verified, freshness enforced, and retrieval benchmarked so agents actually use what they find.

1. **Orphan Remediation Automation** - `python memory/archivist/orphan_remediation.py` takes the 154 orphans from kg-report-cycle5.md and for each: (a) finds the closest parent topic by keyword overlap, (b) proposes a link (file + line to add pointer), (c) applies if confidence >0.8, flags rest for review. Verified: >=50 orphans auto-linked; 0 broken links introduced; report shows before/after orphan count. (pointer: memory/archivist/orphan-remediation-cycle5.md)

2. **Citation Accuracy Verification** - Scan all memory/ files for inline citations (file paths in backticks or "see X" references). Verify each cited file exists and the referenced content is actually there (keyword match). `python memory/archivist/citation_check.py` reports broken/stale citations. Verified: >=200 citations checked; broken ones listed with file:line; clean state returns 0 broken; report actionable. (pointer: memory/archivist/citation-audit-cycle5-report.md) (verified: 2026-11-20 - Builder re-check: citation_check.py ran -> 4708 citations checked, broken listed with file:line (1109), JSON report memory/archivist/citation-check-2026-11-20.json)

3. **Memory Freshness SLA** - Define freshness tiers: HOT (<7 days), WARM (7-30 days), COLD (30-90 days), STALE (>90 days). `python memory/archivist/freshness_report.py` classifies all memory/ files by tier + last-modified. Alert on STALE files in active goal lanes. Verified: report covers 100% of memory/ files; tier assignments correct (spot-check 10); stale alerts fire for known-old files. (pointer: memory/archivist/freshness_report.py) (pointer: memory/researcher/archivist-goal3-freshness-verify-2026-11-20.md) (verified: 2026-11-20 - Builder assist: freshness_report.py verified live (6769 files, HOT/WARM/COLD/STALE tiers) + added --selftest proving tier+alert logic (7/7 incl. stale-alert active-lane + inactive no-alert); fixed lan)

4. **Knowledge Graph Visualization** - Generate an interactive HTML visualization of the knowledge graph (nodes = files, edges = references). Use a force-directed layout (D3.js or similar, embedded in a single HTML file). Output: memory/archivist/kg-visualization.html. Verified: file opens in browser; >=200 nodes visible; clicking a node shows its connections; search/filter works; no external CDN dependency. (pointer: memory/archivist/knowledge_graph.py) (verified: 2026-11-20 - Builder built kg-visualization.html: 442 nodes, 1543 edges, canvas force-directed, search+click+zoom, zero CDN deps. Artifact: memory/builder/archivist-goal4-kg-viz-built-2026-11-20.md)

5. **Cross-Reference Integrity Monitor** - Extend the data integrity checks (Verifier#6) with graph-specific rules: no dangling edges, no self-references, max depth <=3 for pointer chains (A->B->C->D is too deep). `python memory/archivist/xref_monitor.py` runs after every mirror cycle. Verified: monitor catches a deliberately deep chain; clean state passes; report lists violations with fix suggestions. (verified: 2026-11-20 - xref_monitor.py verified live: selftest PASS (A: depth-4 chain caught+isolated, B: clean fixture 0 violations); report at memory/archivist/xref-monitor-report-2026-11-20.md includes per-violation fix )

6. **Archive Compaction** - Identify redundant/overlapping files in memory/goals/archive/ and memory/synthesis/. Merge duplicates, remove superseded entries (keep latest), compress verbose notes. Target: reduce total archive size by >=30% without losing unique information. Verified: before/after file count + byte size reported; spot-check 10 removed files confirms content preserved elsewhere; no broken pointers. (verified: 2026-11-20 - Pass 2 (Builder assist): removed 10 SHA-identical dupes (90.9KB); archive now 365.4KB = 33.4%% reduction from ~549KB original; target >=30%% MET. Evidence: memory/builder/archive-compaction-pass2-2026)

7. **Retrieval Benchmark Suite** - Define 20 standard queries (e.g., "what model does Builder use?", "when was the last portal restart?"). For each: measure time-to-answer + accuracy using the current memory/ structure. Baseline: memory/archivist/retrieval-baseline.json. Verified: all 20 queries run; baseline captured; >=80% accuracy on unambiguous questions; report identifies top-3 slowest queries.

8. **Memory Deduplication Engine** - `python memory/archivist/dedup.py` finds near-duplicate content across memory/ files (similarity >0.85 via shingling or embedding). Proposes merges: keep the more specific file, redirect the other to a pointer. Verified: >=10 duplicate pairs identified; 0 unique content lost after merge; redirected pointers resolve correctly.

9. **Provenance Tracking** - For every memory/ file, record: who created it (agent name), when, what triggered it (goal ref or chat message ID). `python memory/archivist/provenance.py --init` backfills from git log + file headers; future files get provenance header on creation. Verified: >=80% of files have provenance after init; new files created by agents include the header; /api/memory/provenance?file=X returns correct metadata.

10. **Knowledge Graph Export + Import** - Export the full knowledge graph to a standard format (JSON-LD or CSV) for external tooling. `python memory/archivist/kg_export.py --format jsonld` produces memory/archivist/kg-export.jsonld. Verify round-trip: import the export into a fresh dir, re-run integrity check, confirm identical metrics. Verified: export file valid JSON-LD; round-trip preserves node count + edge count; 0 data loss in import. (pointer: memory/archivist/knowledge_graph.py)
